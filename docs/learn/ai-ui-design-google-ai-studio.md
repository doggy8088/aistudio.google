# AI UI 設計：讓 vibe coding 應用程式更好看的 8 種方法

在幾分鐘內從想法到精緻的網頁應用程式。學習如何結合聰明的提示技巧與 AI Studio 內建的 UI 工具，打造美觀的應用程式。

作者：[Geneviève Huskens](https://aistudio.google.com/)
發布於 2026 年 9 月 16 日
閱讀時間 6 分鐘

打造一個能正確運作的應用程式，比打造一個真正美觀的應用程式容易。放任 AI 模型自行發揮，往往會產生感覺千篇一律、老套或雜亂的介面。優秀的介面，正是讓應用程式看起來像隨手做的實驗、還是像真正的產品之間的差別。你不必將就樣板式的樣式，也不必花好幾個小時跟 CSS 提示詞搏鬥。將有針對性的設計提示詞與 AI Studio 的視覺化 Edit 工具搭配使用，你就能親手掌控你的介面。以下八個實用技巧，能讓你的應用程式設計從粗略的原型，提升為精緻、可正式上線的產品。

## 1. 用參考截圖或風格萃取引導你的美學方向

建立一致視覺風格最快的方法，是在 **AI Studio Build** 中，隨著初始提示詞一起上傳一張或多張參考截圖。Gemini 會分析圖片的版面配置、色彩搭配與間距模式，引導你的應用程式的美學方向。我們較新的模型 Gemini 3.8 Flash 與 Gemini 3.7 Flash 尤其擅長從截圖重現 UI。如果你不想直接複製現有的版面配置，也可以運用正確的設計術語，在提示詞中描述你想要的風格。不確定如何把視覺氛圍轉化為正確的文字？先把一張或多張你喜歡的網站截圖上傳到 **AI Studio Playground**，請 Gemini 幫你萃取設計語言：

等 Gemini 產生風格分析後，把那段描述原封不動地複製到你的 **Build** 提示詞中。

## 2. 提示 Gemini 為你的 UI 產生一致、高解析度的圖片

通用的佔位圖片或失效的圖庫圖片連結，會毀掉應用程式的第一印象。別把視覺素材當成事後才想的事，你可以在初始提示詞中直接要求 AI Studio 建立自訂圖片。AI Studio Build 內含 `generate_image` 工具，Gemini 可以呼叫它，使用 **Nano Banana** 為你的應用程式建立一致、高解析度的視覺素材。

為確保此功能正常運作，點選設定齒輪圖示，在 Usage 底下點選 ‘You’re currently using free tier requests’，並選取一個付費的 API 金鑰。這把金鑰將用來支付圖片產生的費用。圖片建立完成後，你可以再切換回使用免費要求。

## 3. 用 Edit 工具修飾、重新設計或替換圖片

應用程式建好後需要微調圖片？你不必把素材匯出到外部圖片編輯器，也不必重新產生整個應用程式。點選頂部工具列的 **Edit tool**，選取應用程式中的任一圖片，再點選魔術棒圖示。

在圖片檢查器中，你有三個即時選項：**Generate edits with Nano Banana**：描述有針對性的視覺變更（例如 *「把天氣改成晴天，配上明亮的藍天」* 或 *「把背景從木頭換成白色大理石」*）。**Create an entirely new image**：提示 Nano Banana 在原地產生全新的素材。**Upload from your device**：一鍵把 AI 產生的佔位圖換成你自己的品牌標誌、產品照片或本機素材。滿意結果後，點選 **Submit** 套用變更。

## 4. 用 Google Fonts 即時試用字體排印

字體排印決定了介面的整體個性。你不必每次想測試新字型就重新產生整個應用程式，可以直接在畫布上即時預覽 Google Fonts。開啟 **Edit tool**，點選任何文字元素。

使用內建的搜尋列，瀏覽並套用 Google Fonts 目錄中的任何字型（例如技術儀表板用的 Space Grotesk、編輯風格部落格用的 Playfair Display，或簡潔 SaaS 工具用的 DM Sans）。在確定之前，你可以先看看不同字型搭配在真實版面上的效果。若要更新單一標題或段落，選取它並點選 Submit。若要一次更新整個應用程式，只要在聊天中這樣要求：*「把所有字型改成 [字型名稱]。」*

## 5. 用 Design Variations 重新設計你的應用程式

當應用程式功能運作良好，但整體版面感覺平淡無奇時，你不必從頭開始。點選 **Edit tool**，再點選 **Design**。

在幕後，AI Studio 的設計引擎會以你現有的程式碼產生一系列完整的 HTML/CSS 重新設計，同時嚴格保留你所有的文字、表單與互動邏輯。你可以讓 AI Studio 自動產生不同的視覺方向，也可以用自訂提示詞引導重新設計：**Editorial & Refined**：*「以襯線字體標題、寬裕的留白與明亮的白色背景重新設計。」***Technical & Systematic**：*「重新設計為高密度的資料終端機，使用等寬字體的中繼資料與可見的格線邊框。」***Warm & Approachable**：*「以柔和的粉彩卡片、膠囊形按鈕與友善的圓角重新設計。」* 並排預覽每個候選設計，點選 ‘submit’ 即可一鍵套用你最喜歡的外觀。

## 6. 透過直接檢查元素，精準調整像素級的內距與樣式

想修一張太擁擠的卡片或沒置中的按鈕，卻得打字輸入 *「幫左邊第二個容器再加 8 像素的內距」*，既繁瑣又不精確。改用 **Edit tool** 切換，直接點選你想調整的個別 DOM 元素。你可以在視覺化檢查器中手動微調內距、邊距、元素尺寸與十六進位色碼，再點選 **Submit** 套用變更。

在這裡花短短五分鐘調整間距與對齊，就能大幅把應用程式從粗略原型提升為精緻產品。直接檢查元素也很有用，當你想確切告訴 AI Studio 要編輯應用程式的哪個部分時。例如，點選一個元素並這樣要求：*「這個容器應該佔據登陸頁的 70%。請相應調整所有其他元素的大小。」*

## 7. 用 Annotate 模式在幾秒內讓 UI 去蕪存菁

模型喜歡幫忙，意思是有時會做過頭，加入多餘的標籤晶片、重複的狀態徽章或不必要的小工具。事實上，辨識 vibe coding 應用程式最快的方法，就是看它是否有許多毫無用途、沒有實際意義的標籤與文字元素。用批判的眼光檢視你的應用程式，問自己哪些東西不是絕對必要、可以移除。接著，與其打一大段文字列出每個想移除的元素，不如用視覺標註來清理：

點選 **Edit tool** 並選取 **Annotate**。在每個想刪除的按鈕、標籤或區塊周圍畫一個圈。在提示框中輸入 **「移除所有圈選的元素」** 並點選提交。Gemini 會一併讀取你的視覺標記與程式碼，乾淨地移除雜亂元素，又不會破壞周圍的版面配置。Annotate 模式也是修復視覺錯誤的好方法：圈出重疊的文字或損壞的容器，讓模型確切知道該聚焦在哪裡。

## 8. 從 Gallery 混搭應用程式，借用經過驗證的 UI 模式

最後，如果你面對一片空白的畫布，或不確定如何組織複雜的多模態 UI，可以從經過驗證的基礎開始。[**AI Studio App Gallery**](https://aistudio.google.com/apps?source=showcase&showcaseTag=featured) 會持續更新精選的小程式，展示我們最新模型的功能，我們也會盡力讓它們看起來非常出色。

點進任何吸引你目光的 Gallery 應用程式，按下 Remix 按鈕。你會立即在 Build 模式中得到一份可編輯的應用程式副本，讓你檢視其提示詞與 UI 元件在幕後是如何組織的。接著，你可以提示 AI Studio 把這個應用程式變成你自己的：*「保留這個完全相同的視覺風格與版面配置，但把它變成一個關於 [你的主題] 的小程式。」*

## 讓你的下一個想法成真

出色的設計不必拖慢你的腳步。當你把前期的風格引導與 AI Studio Edit 工具的實作掌控結合起來，你就能兩全其美：vibe coding 的速度，加上自訂介面的精緻。無論你是在打造內部工具、週末實驗專案，還是面向客戶的產品，這些小小的視覺調整正是讓應用程式真正令人難忘的關鍵。準備好試試了嗎？前往 [Google AI Studio Build](https://aistudio.google.com/apps) 在你的下一個專案中測試這些工作流程，或跳進 [App Gallery](https://aistudio.google.com/apps?source=showcase&showcaseTag=featured) 混搭一個精選應用程式，把它變成你自己的。
