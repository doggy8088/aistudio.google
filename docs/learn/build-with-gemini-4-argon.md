# 使用 Gemini 4 Argon 建置

把粗略的想法、照片與雜亂的檔案，變成能運作的應用程式、可遊玩的 3D 世界與精緻的專案——你只需要描述你想要什麼。

![Geneviève Huskens](https://www.gstatic.com/aistudio-static/editorial/page-msrgq2u0/genevieve-huskens.webp)

**Gemini 4 Argon** 是我們最新的前沿模型，旨在把你最大膽的想法從頭到尾完整實現。無論你是用 vibe coding 打造第一個網頁應用程式、把書桌的照片變成可遊玩的 3D 遊戲，或是把一資料夾雜亂的檔案整理成互動式儀表板，Argon 都能把白話描述、草圖與上傳的檔案，變成可以遊玩、使用與分享的真實專案。Argon 能在漫長的多步驟專案中保持上下文，深入遵循你的創意方向，並帶來強得多的版面、設計與 3D 空間感。你不需要從零開始寫程式碼就能開始建置。在 [Google AI Studio Playground](https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon) 試用起始提示詞、在 [AI Studio Build](https://aistudio.google.com/build) 遊玩並混搭發表應用程式，或探索下方的指南。

## 在 Playground 試用起始提示詞

想從零測試一個想法嗎？點選下方任一提示詞，即可在 [Google AI Studio Playground](https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon) 開啟與 Gemini 4 Argon 的預填對話：• [**建立 3D 軌道重力沙箱**](https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon&prompt=Build%20an%20interactive%203D%20orbital%20gravity%20simulator%20in%20a%20single%20HTML%20file%20using%20Three.js.%20Let%20me%20click%20and%20drag%20to%20launch%20new%20planets%20with%20different%20masses%20and%20velocities%2C%20visualize%20their%20orbital%20trails%2C%20and%20adjust%20gravity%20and%20time%20speed%20with%20sliders.)：在 3D 空間中發射行星，即時觀看它們的軌道軌跡與重力牽引如何互動。• [**把照片變成 3D 構想**](https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon&prompt=I%20want%20to%20upload%20a%20photo%20of%20a%20room%20or%20desk%E2%80%94help%20me%20turn%20the%20objects%20in%20it%20into%20an%20interactive%203D%20miniature%20scene%20I%20can%20explore%20in%20my%20browser.)：上傳房間或書桌的照片，把其中的物品變成可互動的 3D 微縮世界。• [**建立互動式財務模擬器**](https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon&prompt=Create%20an%20interactive%20SaaS%20runway%20and%20pricing%20scenario%20simulator%20in%20a%20single%20HTML%20file.%20Include%20sliders%20for%20monthly%20growth%2C%20churn%2C%20tier%20pricing%2C%20and%20hiring%20plan%2C%20and%20render%20live%20charts%20showing%2024-month%20cash%20flow%20and%20break-even%20date.)：以即時敏感度滑桿與圖表，模擬定價級距、招募計畫與 24 個月的現金流。
