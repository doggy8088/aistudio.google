幾分鐘內從構想變成可實際運作的文字轉語音應用程式——只要描述你想要的內容，Gemini 就會為你建置。無須撰寫程式碼。

### 用後續提示詞加入功能

- 新增控制項：「加入速度滑桿」或「加入切換開關來調整語調。」
- 匯出選項：「讓使用者可以把音訊下載為 MP3。」
- UI 改良：「加入深色模式切換開關。」
