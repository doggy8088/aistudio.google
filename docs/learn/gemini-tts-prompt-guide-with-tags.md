# 如何為 Gemini 3.1 的文字轉語音模型下提示詞

Gemini 3.1 Flash 文字轉語音（TTS）是一個新模型，你可以透過指示，讓它給出你想要的精確音訊表現。在這篇文章中，我將分享一些以提示詞引導這個模型的技巧，並分享一些展現其強項的範例。

作者：[fofr](https://x.com/fofrAI)

`gemini-3.1-flash-tts-preview` 開箱即能原生理解逐字稿，判斷你的文字應該如何唸出來。沒有額外提示的簡單逐字稿，聽起來就很自然。但 3.1 Flash TTS 也附帶了能讓你引導它的工具。

你可以給模型充分的上下文，例如一份音訊設定檔：誰在說話、他們如何說話、他們的聲音聽起來如何等等。你也可以描述場景：他們在哪裡、在做什麼、周圍的環境，並提供任何額外的「導演筆記」來引導演出。模型會運用這些資訊，生成在該情境下聽起來恰如其分的語音。

你現在也可以使用標籤，來控制逐字稿特定部分的唸法。標籤是像 [whispers] 或 [laughs] 這樣的行內修飾詞，讓你能細緻地控制唸法。你可以用它們改變一句台詞或一段逐字稿的語氣、節奏與情緒氛圍。你也可以用它們為演出加入插話和一些其他的非語言聲音，例如 [cough]、[sighs] 或 [gasp]。

你能使用的標籤沒有任何限制。你可以在那些 [] 括號裡放進各種創意內容，模型永遠會盡力理解並詮釋它們。

## 上下文與演出

透過提供細膩的指示，例如精確的地區口音、氣音這類具體特徵，或是節奏，你可以運用模型的上下文感知能力，生成動態、自然且富有表現力的音訊演出。這樣就不需要為了每個微小調整都使用標籤。

當逐字稿與提示詞彼此對齊時，效果最好，也就是讓「誰在說」與「說什麼」和「如何說」相互吻合。

## 提示詞結構

一個好的提示詞，會在逐字稿之前包含幾個關鍵元素：音訊設定檔、場景、導演筆記。這些段落全都是選填的，但它們能幫助模型理解你想要的上下文與演出。你可以把這些元素看成一份系統指令，讓不同的逐字稿生成聽起來一致的輸出。

## 音訊設定檔

這是你聲音的人設。你可以定義一個角色身分、原型，以及年齡或背景等任何其他特徵。給你的角色取個名字，有助於讓模型聚焦，並把整場演出串連起來。在設定場景與上下文時，你可以用名字稱呼這個角色。定義他們的身分也很有幫助，例如他們是電台 DJ、Podcaster，還是新聞播報員。

## 場景

場景負責鋪陳舞台。地點、氛圍與環境細節定義了語氣與感受。你應該描述角色周圍正在發生什麼事，以及這些事如何影響他們。場景為整段互動提供環境上下文，並以細膩而自然的方式引導演出。像是繁忙清晨咖啡店裡的對話、DJ 在他們的專業錄音室中，或是繁忙機場裡的廣播。

## 導演筆記

導演筆記是給模型的演出指導。最常見的指示是風格、節奏與口音，但模型並不限於這些。歡迎加入自訂指示，涵蓋對你的演出重要的任何額外細節，詳略程度可依需要自由拿捏。

## 風格

風格決定了生成語音的基調。加入歡快、充滿活力、放鬆或無聊等描述來引導演出。盡量描寫得具體，並提供必要的細節。說「充滿感染力的熱情。聽眾應該感覺自己正置身於一場盛大又令人興奮的社群活動之中」，效果遠比只說「充滿活力與熱情」好得多。

你甚至可以試試配音業界常用的術語，例如「聲音微笑」。你想疊加多少風格特徵都可以。

## 口音

描述你想要的口音。你描述得越具體，結果就越好。例如，使用「在英格蘭克羅伊登聽到的英式英語口音」，而不是只說「英式口音」。

## 節奏

你也可以指定整段作品的整體節奏，以及全程的節奏變化。
