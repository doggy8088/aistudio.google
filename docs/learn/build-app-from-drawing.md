### 啟用 AI 圖片編輯

- **草圖要畫得清楚**：先在紙上畫出你的應用程式版面，著重在標頭、頁尾與側邊欄等主要區塊
- **上傳高品質的照片**：在光線充足的地方，從正上方拍攝你的草圖的高品質照片，以減少任何扭曲
- **在對話中描述並調整**：在 Build 模式的輸入框中，詳細描述你想打造的內容，包括應用程式的主要用途與期望的配色方案
