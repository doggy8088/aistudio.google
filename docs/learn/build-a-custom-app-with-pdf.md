# 在 Google AI Studio 中打造自訂網頁應用程式來分析 PDF

用白話英文描述你想要的 PDF 工具。Build 模式會建立一個可實際運作的網頁應用程式，協助你審閱文件、擷取表格，並與團隊分享。

## 把重複的 PDF 工作變成網頁應用程式

當團隊每次都要對發票、合約或報告進行相同的審閱時，自訂網頁應用程式可以省下不少步驟。加入檔案上傳區、操作按鈕與乾淨的摘要檢視，完全配合你的工作流程打造。

## 用白話英文描述你的需求

在 Google AI Studio 中開啟 Build 模式，描述你的工具。你可以要求建立發票檢查器、研究論文閱讀器，或並排合約檢視器。Build 模式會建立介面，並連結 Gemini 視覺功能，讀取圖表、表格與掃描文件。

## 每次都得到一致的表格

告訴 Build 模式，你的應用程式應從每份 PDF 擷取哪些確切的欄位或欄位資料。你的應用程式會在每次上傳時回傳相同的乾淨表格或可下載的試算表，無須手動複製貼上。
