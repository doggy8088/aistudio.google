# 在 AI Studio 中直接解鎖免費 API 點數，搭配 Google AI 方案

Google AI Pro 與 Ultra 包含每月 Gemini API 點數，現在你可以在 AI Studio 中透過一個引導流程直接領取。連結付費金鑰，突破每日上限，盡情使用 Gemini API。

## 將 Google AI 方案福利延伸到 Gemini API，直接在 AI Studio 中完成

Google AI Pro 與 Ultra 方案每月包含促銷 Google Cloud 點數，每個月的點數效期為 12 個月。你可以把點數套用到自己的 Gemini API 金鑰，在自己的應用程式中使用，適用於任何 Gemini 模型。使用與 Google AI Pro 或 Ultra 方案關聯的 @gmail.com 地址登入 AI Studio，留意左側選單中的 **Claim your free API credits** 卡片。點選後，一個引導式對話方塊會帶你完成專案與 API 計費設定，直到領取點數，並可搭配 API 金鑰直接在 AI Studio 中使用。從那之後，你的 API 點數會先支付費用，讓你突破每日基準用量，繼續打造。
