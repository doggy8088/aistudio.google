## Grounding with Google Search {#grounding-with-google-search}

「Grounding with Google Search」是一項提供 Grounded Results 與 Search Suggestions 的 Service，可透過 Google AI Studio（作為 Unpaid Service）使用，也可透過 Gemini API（作為 Paid Service）使用。「Grounded Results」是指 Google 使用最終使用者的提示詞、你可能提供的上下文資訊（如適用），以及 Google 搜尋引擎的結果所產生的回應。「Search Suggestions」（亦稱為 Search Entry Points）是指 Google 隨 Grounded Results 一併提供的搜尋建議。若 Grounded Result 被點選，目的地頁面受另外的條款（非本條款）規範。若 Search Suggestion 被點選，則 [google.com](http://google.com) 目的地頁面受 [Google 服務條款](https://policies.google.com/terms) 規範。「Links」是指取得網頁的任何其他方式（包括超連結與 URL），可能包含於 Grounded Result 或 Search Suggestion 中。Links 也包括隨這些取得網頁方式一併提供的標題或標籤。除你的網域名稱外，你不得就 Search Suggestions 或 Grounded Results 中的 Links 主張任何智慧財產權的所有權。

### 使用限制 {#use-restrictions-grounding}

* 你只能在由你擁有並營運的應用程式中使用 Grounding with Google Search，且只能向提交提示詞的最終使用者顯示 Grounded Results 及相關的 Search Suggestion(s)。

* 你不得——也不得允許你的最終使用者或任何第三方——儲存（下文規定者除外）、快取、複製、框嵌 Grounded Results 或 Search Suggestions，對其實施任何點選追蹤、Link 追蹤或其他監控（下文規定者除外），或對其進行聯播、轉售、分析、以其訓練，或以其他方式從中學習。

  * 你得儲存 Grounded Result(s) 的文字（不含 Links）：(1) 僅供在你的應用程式中評估與最佳化 Grounded Results 的顯示，且儲存期間以你顯示後三十（30）天為限；以及 (2) 於你的應用程式之最終使用者的聊天記錄中，儲存期間以六（6）個月為限，且僅用於讓該最終使用者查看其聊天記錄。

  * 你得監控最終使用者與你的應用程式介面的互動；但你不得追蹤這些互動是否特定針對某個 Search Suggestion 或 Grounded Result（無論全部或部分，包括任何特定 Link）。


* 除非經 Google 書面許可，你：(1) 不得修改 Grounded Results 或 Search Suggestions，或將任何其他內容穿插其中；以及 (2) 不得在任何 Link 或 Search Suggestions 與相關目的地頁面之間放置任何插頁式內容、將最終使用者重新導向離開目的地頁面，或縮小、移除或以其他方式妨礙任何目的地頁面的完整顯示。


### 資料蒐集與 Google 如何使用你的資料 {#data-collection}

除了上述一般條款（「[Unpaid Services](/docs/terms/#unpaid-services)」與「[Paid Services](/docs/terms/#paid-services)」下的「How Google Uses Your Data」）外，使用 Grounding with Google Search 時，Google 會儲存提示詞、你可能提供的上下文資訊及輸出三十（30）天，用於建立 Grounded Results 與 Search Suggestions，且所儲存的資訊可用於支援 Grounding with Google Search 之系統的除錯與測試。透過 Gemini API 付費配額使用 Grounding with Google Search 時，此除錯與測試系統的處理係依照[適用於 Google 為資料處理者之產品的資料處理附錄](https://business.safety.google/processorterms/)進行。

本「Grounding with Google Search」小節於協議終止後仍繼續有效（如適用）。

[Client Application Guidelines](https://support.google.com/adsense/answer/10926790) 適用於你對 Grounding with Google Search 的使用。就 Client Application Guidelines 而言，你使用 Grounding with Google Search 的應用程式視為 Approved Applications。
