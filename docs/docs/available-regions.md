# Google AI Studio 與 Gemini API 的可用地區

如果你是在嘗試開啟
[Google AI Studio](https://aistudio.google.com/) 時來到本頁，
表示你所在的地區可能不受支援。支援的地區清單請見下方章節。

其他存取要求（例如
[年齡要求](/docs/troubleshoot-ai-studio/#age-requirements)）請參閱
[排解 Google AI Studio 問題](/docs/troubleshoot-ai-studio/) 與我們的
[服務條款](/docs/terms/)。

## 可用地區 {#available-regions}

      注意：Colab 使用者請留意——地區限制是以
      **Colab 執行個體** 所在的地區為準，而不是以 **使用者**
      所在的地區為準。你可以使用
      `!curl ipinfo.io` 查看 **Colab 執行個體** 的位置
