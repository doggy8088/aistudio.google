# 濫用監控 {#abuse-monitoring}

Google 致力於以負責任的態度開發與使用 AI。為確保 Gemini API 的安全與完整性，我們制定了以下政策指南。使用 Gemini API 即表示你同意本指南、[Gemini API 附加服務條款](/docs/terms/)以及生成式 AI 的[禁止使用政策](https://policies.google.com/terms/generative-ai/use-policy)。

## 我們如何監控濫用行為 {#how-we-monitor-for-misuse}

Google 的信任與安全團隊會結合自動化與人工流程，偵測 Gemini API 與 Google AI Studio 的潛在濫用行為，以落實我們的政策。

* **自動偵測**：自動化系統會掃描 API 使用情形，檢查是否違反禁止使用政策，例如仇恨言論、騷擾、色情內容與危險內容。

* **人工偵測**：若某個專案持續出現可疑活動，可能會被標記，交由獲授權的 Google 人員進行人工審查。

## 我們如何處理資料 {#how-we-handle-data}

Google 會保留下列資料五十五（55）天，用於偵測並防止違反禁止使用政策的行為，以維護服務的安全與安全性，以及履行法律或監管揭露要求：

* **提示詞**：你提交給 API 的文字提示詞。

* **上下文資訊**：你隨提示詞一併提供的任何額外上下文。

* **輸出**：Gemini API 產生的回應。

## 我們如何調查潛在問題 {#how-we-investigate-potential-issues}

當提示詞或模型輸出被安全篩選器與上述濫用偵測系統標記時，獲授權的 Google 員工可以評估被標記的內容，並依既定的指南與政策確認或修正其分類或判定結果。資料僅能由獲授權的 Google 員工透過內部治理評估與審查管理平台存取，供人工審查之用。為濫用監控而記錄的資料，僅用於政策執行與防止政策違規，不會用於訓練或微調任何 AI/ML 模型（專門用於政策執行的模型除外）。

## 與你協作，確保符合政策 {#policy-compliance}

若你使用 Gemini 的方式不符合我們的政策，我們可能採取下列措施：

* **主動聯繫**：我們可能會透過電子郵件聯繫你，了解你的使用情境，並共同尋找讓你的使用方式符合政策的方法。

* **暫時的使用限制**：我們可能會限制你存取 Gemini API，例如調整速率限制，或變更回答特定請求的模型。

* **暫時停權**：我們可能會暫時暫停你存取 Gemini API。

* **關閉帳號**：作為最後手段，對於嚴重違規者，我們可能會永久關閉你對 Gemini API 與其他 Google 服務的存取權限。

若我們就停權或帳號關閉事宜聯繫你，也會提供申訴連結供你提出申訴。

## 適用範圍 {#scope}

本政策指南適用於 Gemini API 與 AI Studio 的使用。
