# 意見回饋 {#feedback}

Google AI Studio 提供多種方式，讓你針對模型輸出、產生的成品與 API 請求記錄提交意見回饋。
本政策適用於在 Google AI Studio 各處提交的所有意見回饋，包括回應評分（例如
喜歡與不喜歡）、書面留言，以及偏好投票（例如
Inline Preference Voting 與 Build Arena 模式）。

## 我們為什麼要這樣做？ {#why-inline-preference-voting}

我們持續致力於改善 AI 模型與服務。你的意見回饋有助於我們提供、改善與開發 Google 產品與服務及機器學習技術，包括 Google 的企業功能、產品與服務，並符合
[Gemini API 附加服務條款](/docs/terms/)與
[隱私權政策](https://policies.google.com/privacy)。

## 意見回饋包含哪些資料？ {#included-data}

為了針對模型與功能做出明智的決策，當你在 Google AI Studio 提交意見回饋時，我們會收集特定資料：

*   **提示詞與回應**：我們會記錄你提交意見回饋的那次互動或對話中的提示詞與回應，
    包括任何上傳的檔案或媒體。當你參與比較式偏好評估時，
    我們也會記錄所呈現的多個回應選項，以便了解你選擇的背景脈絡。

*   **你的評分、投票或留言**：我們會記錄你給出的評分（例如
    喜歡或不喜歡）、你在投票中偏好的回應、你選取的任何意見回饋類別，
    以及你提交的任何書面留言。

*   **使用詳情**：這包括你互動或對話中的技術與操作細節，
    例如產生回應的模型、模型參數與系統中繼資料等資訊。


### 依介面區分的意見回饋 {#feedback-by-surface}

在 Google AI Studio 的不同介面中都可以提交意見回饋，
所擷取的背景資訊略有差異：

*   **AI Studio Playground**：在 Playground 中，可以透過
    回應評分（喜歡或不喜歡），或並排的 Inline Preference
    Voting 提交意見回饋。記錄的資料包括對話記錄、提示詞、模型
    回應、上傳的媒體或檔案、參數設定、意見回饋與使用詳情。

*   **AI Studio Build**：在 Build（包括 Build Arena）中，可以針對
    產生的程式碼、應用程式輸出與比較式模型評估提交意見回饋。
    記錄的資料包括建置指令與提示詞、產生的
    應用程式程式碼與輸出、比較投票或評分、隨附的
    留言與使用詳情。

*   **Gemini API Logs**：在 Logs and Datasets 檢視器中，可以針對
    個別的 Gemini API 請求記錄提交意見回饋。記錄的資料包括
    特定的 API 記錄條目（包括請求酬載、模型回應、
    參數與中繼資料），以及任何意見回饋與使用詳情。記錄資料儲存與資料集共用的詳情，請參閱
    [資料記錄與共用](/docs/logs-policy/)政策。


## Inline Preference Voting {#inline-preference-voting}

在 Google AI Studio 中，你偶爾會看到針對你的提示詞、兩個不同回應的並排比較。
這是我們偏好投票系統的一部分。系統會請你選擇偏好的回應，
這有助於我們了解使用者覺得哪些模型輸出最有幫助。

## 你的隱私 {#privacy}

**請勿針對包含敏感、機密或個人資訊的對話、提示詞、回應或記錄提交意見回饋**。提供意見回饋
一律出於自願。
