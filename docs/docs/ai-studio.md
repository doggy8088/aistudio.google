# Google AI Studio 總覽

[Google AI Studio](https://aistudio.google.com/) 是用於以 Gemini 模型建立提示詞原型、從自然語言提示詞建置全端應用程式，以及管理 Gemini API 專案的網頁工作區。無需本機設定即可直接在瀏覽器中開始，準備就緒後再匯出程式碼或發佈正式應用程式。

[開啟 Google AI Studio](https://aistudio.google.com/)


  

**[Playground 快速入門](/docs/ai-studio-quickstart/)**

測試 Gemini 模型、調整執行設定，並匯出可直接執行的 API 程式碼。


  

**[建置應用程式](/docs/aistudio-build-mode/)**

以 vibe coding、預覽並發佈全端網頁應用程式與原生 Android 應用程式。


  

**[AI Studio 中的代理](/docs/aistudio-agents/)**

以預先建置的範本與沙箱，透過視覺化方式建立受管理代理的原型。


## 選擇你的工作流程 {#choose-your-workflow}

Google AI Studio 匯集了四種主要工作流程。請選擇符合你想完成事項的入門指南。

| 目標 | AI Studio 介面 | 入門指南 |
| :--- | :--- | :--- |
| 測試提示詞、模型與工具 | Playground | [Playground 快速入門](/docs/ai-studio-quickstart/) |
| 無需撰寫 API 呼叫即可建立受管理代理原型 | Playground（Agents） | [AI Studio 中的代理](/docs/aistudio-agents/) |
| 使用機密、Firebase 或 Workspace API 建置全端網頁應用程式 | Build mode | [建置應用程式總覽](/docs/aistudio-build-mode/)與[全端網頁應用程式](/docs/aistudio-fullstack/) |
| 建置原生 Kotlin 與 Jetpack Compose Android 應用程式 | Build mode（Android） | [Android 應用程式](/docs/aistudio-android/) |
| 將應用程式發佈至 Cloud Run 或連結自訂網域 | Publish 面板 | [發佈你的應用程式](/docs/aistudio-deploying/)與[自訂網域](/docs/aistudio-custom-domains/) |
| 提高每日上限或領取每月 Gemini API 點數 | 帳戶與方案 | [Google AI 方案](/docs/google-ai-plans/) |
| 為機構啟用 AI Studio 或診斷錯誤 | 管理與疑難排解 | [Google Workspace 存取](/docs/workspace/)與[疑難排解 AI Studio](/docs/troubleshoot-ai-studio/) |

## 管理你的 Gemini API 帳戶 {#manage-api-account}

Google AI Studio 同時也是 Gemini API 專案的資訊主頁。請使用下方指南管理金鑰、計費、驗證與記錄：

* [使用 Gemini API 金鑰](/docs/api-key/)：建立授權金鑰、匯入 Google Cloud 專案，以及管理金鑰限制。
* [計費](/docs/billing/)：從免費層級升級、新增 Prepay 點數、設定每月專案支出上限，以及監控用量。
* [專案與帳號驗證](/docs/verification/)：為免費層級專案或遭標記的帳戶完成行動裝置驗證。
* [日誌](/docs/logs-datasets/)：檢視已儲存的 Gemini API 要求、設定保留期間，以及匯出資料集。

## 後續步驟 {#whats-next}

* 在 [Playground 快速入門](/docs/ai-studio-quickstart/)中執行你的第一個提示詞。
* 使用[建置應用程式總覽](/docs/aistudio-build-mode/)建立網頁或 Android 應用程式。
* 在 [Google AI 方案](/docs/google-ai-plans/)中比較訂閱額度與 API 點數。
* 在[疑難排解 AI Studio](/docs/troubleshoot-ai-studio/)中診斷登入、地區、配額或權限錯誤。
