# 使用 Gemini API 進行微調

隨著 Gemini 1.5 Flash-001 於 2025 年 5 月淘汰，Gemini API 和 AI Studio 目前已無支援微調的模型，不過 [Gemini Enterprise Agent Platform](https://cloud.google.com/gemini-enterprise-agent-platform/models/gemini-use-supervised-tuning) 仍提供微調支援。

我們目前沒有立即推出微調支援的計畫，但如果微調對您的使用案例很重要，歡迎[在開發人員論壇上告訴我們](https://discuss.ai.google.dev/c/gemini-api/4)。
