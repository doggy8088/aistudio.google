# Gemini Developer API 定價

先以寬裕的額度免費開始建構，再透過預付與隨用隨付的定價擴展規模，支援您可投入生產環境的應用程式。


  

**免費**

適合剛開始使用 Gemini API 的開發人員與小型專案。

  

---


  
  *  僅能有限存取部分模型
  *  免費的輸入與輸出權杖
  *  可使用 Google AI Studio
  *  內容會用於改善我們的產品[*](/docs/terms/)

  

  
  [免費開始使用](https://aistudio.google.com)


  

**付費**

適合需要更高用量與進階功能的生產應用程式。

  

---


  
  *  生產部署享有更高的速率限制
  *  可使用上下文快取
  *  Batch API（成本降低 50%）
  *  可使用 Google 最先進的模型
  *  內容**不**會用於改善我們的產品[*](/docs/terms/)

  

  
  [升級至付費版](https://aistudio.google.com/api-keys)


  

**企業版**

適合企業部署，由 [Gemini Enterprise Agent Platform](https://cloud.google.com/gemini-enterprise-agent-platform) 驅動。

  

---


  
  *  包含付費版的所有功能，並可額外選用：
  *  專屬支援管道
  *  進階安全性與法規遵循
  *  預配輸送量
  *  依用量提供量價折扣
  *  ML ops、model garden 等更多功能

  

  
  [聯絡銷售團隊](https://cloud.google.com/contact)

## 備註 {#notes}

*   **代理式影片理解**：使用代理式影片理解時，權杖用量會依模型載入的內容而變，而非依完整的影片長度計算。對於長篇影片，這通常可減少多達 88% 的輸入權杖，不過權杖數量取決於查詢複雜度與動態取樣深度（對於細節豐富的視覺片段，可能超過 1 FPS）。請參閱[代理式影片理解](/docs/video-understanding/#agentic-video-understanding)。

*   **文件權杖計費**：`DOCUMENT` 模態的權杖（例如 PDF）按圖片權杖費率計費。在 API 回應中，這些權杖會出現在 `DOCUMENT` 模態下，位於 `promptTokensDetails` 內。

*   在所有[可用地區](/docs/available-regions/)，Google AI Studio 皆可免費使用。詳情請參閱[計費常見問題](/docs/billing/)。

*   價格可能與此處列出的價格以及 Gemini Enterprise Agent Platform 提供的價格不同。Gemini Enterprise Agent Platform 的價格請參閱 [Gemini Enterprise Agent Platform 定價頁面](https://cloud.google.com/products/gemini-enterprise-agent-platform)。

*   如果您使用[動態擷取](/docs/google-search/)來最佳化成本，只有回應中包含至少一個來自網路的接地支援 URL 的請求，才會收取使用 Google 搜尋接地的費用。Gemini 的費用一律適用。速率限制可能變更。

*   **Search Grounding 速率限制**：在 Gemini Developer API 上，Gemini 3 及更新模型的使用 Google 搜尋接地，在所有付費級中，每個專案受每日 1,500 次請求（RPD）的預設每日速率限制約束，並於太平洋時間每日午夜重設。對於需要更高每日上限的大量生產工作負載，建議使用 [Vertex AI](https://cloud.google.com/vertex-ai/generative-ai/docs/grounding/grounding-with-google-search#considerations)，其預設配額為每日 1,000,000 次搜尋查詢。
