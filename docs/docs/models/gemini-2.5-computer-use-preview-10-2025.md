# Gemini 2.5 電腦操作模型


!!! warning " "

      此模型已於 **2026 年 7 月 28 日**[關閉](/docs/deprecations/)；請遷移至
      [Gemini 3.8 Flash](/docs/models/gemini-3.8-flash/) 或其他內建
      [電腦操作](/docs/computer-use/)支援的
      [Gemini 3](/docs/models/#gemini-3) 模型，以免服務中斷。


專為直接與介面互動設計的代理能力模型，讓 Gemini 能感知並瀏覽數位環境。Gemini 2.5 Computer Use 最適合需要視覺推理與精確游標控制的瀏覽器自動化、多步驟軟體任務和 UI 測試。

請造訪[電腦操作](/docs/computer-use/)頁面，查看功能與能力的完整說明。
