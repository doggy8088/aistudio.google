# Gemini 3.8 Flash

Gemini 3.8 Flash 是我們最聰明的 Flash 模型，專為長時間的軟體工程、自主代理與複雜的企業工作流程打造，同時保有 Flash 的速度與成本效益。

[在 Google AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=gemini-3.8-flash)
