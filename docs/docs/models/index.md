# 模型

不確定從何開始嗎？請閱讀[選擇模型](/docs/choosing-a-model/)，比較各 Gemini 模型的推理深度、速度與成本，或參閱[最新 Gemini 模型](/docs/latest-model/)。

## Gemini 4 {#gemini-4}


  

**Gemini 4 Carbon**

我們最強大的推理模型，專為複雜的軟體工程、多模態知識工作、科學推理與網路安全防禦而打造。

*   *Model code* **gemini-4-carbon**
  *   *Context* **1M tokens**
  *   *Max output* **64K / 1M tokens**
  *   *Modalities* **Text, Image, Audio, Video, PDF**

  

  
  [在 AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=gemini-4-carbon) [查看模型](/docs/models/gemini-4-carbon/)


  

**Gemini 4 Neon**

具備前沿級智慧，端到端任務完成速度快，適用於複雜的軟體工程、知識工作與科學工作流程。

*   *Model code* **gemini-4-neon**
  *   *Context* **1M tokens**
  *   *Max output* **64K / 1M tokens**
  *   *Modalities* **Text, Image, Audio, Video, PDF**

  

  
  [在 AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=gemini-4-neon) [查看模型](/docs/models/gemini-4-neon/)


  

**Gemini 4 Hydrogen**

將尖端智慧帶給所有人，兼具速度與效率，適合日常程式設計與代理工作流程。

*   *Model code* **gemini-4-hydrogen**
  *   *Context* **1M tokens**
  *   *Max output* **64K / 1M tokens**
  *   *Modalities* **Text, Image, Audio, Video, PDF**

  

  
  [在 AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=gemini-4-hydrogen) [查看模型](/docs/models/gemini-4-hydrogen/)


  

**Gemini 4 Argon**

我們高效率的 Gemini 4 前沿推理模型，在複雜的程式設計、代理、數學與科學任務上，相較於 Gemini 4 Carbon 能以更快的回應速度與更低的每回合 token 花費完成任務。

*   *Model code* **gemini-4-argon**
  *   *Context* **1M tokens**
  *   *Max output* **64K / 1M tokens**
  *   *Modalities* **Text, Image, Audio, Video, PDF**

  

  
  [在 AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=gemini-4-argon) [查看模型](/docs/models/gemini-4-argon/)

## Gemini 3 {#gemini-3}


  

**[Gemini 3.8 Flash](/docs/models/gemini-3.8-flash/)**

我們上一代的 Flash 模型，適用於軟體工程、自主代理與複雜的企業工作流程。


  

**[Gemini 3.8 Live](/docs/models/gemini-3.8-live/)**

多數低延遲語音代理體驗的預設 Live API 模型，不會因推理造成延遲。


  

**[Gemini 3.8 Live Extended Thinking](/docs/models/gemini-3.8-live-extended-thinking/)**

適用於語音互動的高推理 Live API 模型，建議在需要更強背景推理時使用。


  

**[Gemini 3.8 Flash TTS](/docs/models/gemini-3.8-flash-tts/)**

旗艦級創意文字轉語音模型，具備錄音室等級的語音擬真度、富有表現力的演繹、Voice design 與 Voice replication。


  

**[Gemini 3.8 Flash-Lite TTS](/docs/models/gemini-3.8-flash-lite-tts/)**

快速且具成本效益的文字轉語音模型，適用於大量製作、即時語音代理串聯，以及 Voice replication。


  

**[Gemini 3.6 Flash](/docs/models/gemini-3.6-flash/)**

我們上一代的 Flash 模型，在一般代理與日常任務中兼顧速度與多模態能力。


  

**[Gemini 3.5 Flash-Lite](/docs/models/gemini-3.5-flash-lite/)**

我們速度最快、最具成本效益的 3.5 模型，專為高輸送量執行而設計。


  

**[Gemini 3.1 Flash-Lite](/docs/models/gemini-3.1-flash-lite/)**

以遠低於大型模型的成本，提供足以媲美前沿等級的效能。


  

**[Nano Banana 2.1](/docs/models/gemini-nano-banana-2.1/)**

高效率的圖片生成與編輯模型，視覺品質、排版與多回合一致性皆有所提升。


  

**[Nano Banana 2](/docs/models/gemini-3.1-flash-image/)**

強大且高效率的圖片生成與編輯，專為速度與大量使用情境最佳化。


  

**[Nano Banana 2 Lite](/docs/models/gemini-3.1-flash-lite-image/)**

延遲極低且具成本效益的圖片生成與編輯，專為大量互動式使用情境設計。


  

**[Nano Banana Pro](/docs/models/gemini-3-pro-image/)**

頂尖的圖片生成與編輯模型，能以高度情境化的方式原生創作圖片。


  

**[Gemini 3.5 Transcribe](/docs/models/gemini-3.5-transcribe/)**

低延遲的語音轉文字模型，具備以語句為單位的語言偵測、說話者分離與逐詞時間戳記。


  

**[Gemini Omni Flash](/docs/models/gemini-omni-flash/)**

生成並編輯最長 15 秒的影片，具備原生音訊、關鍵影格插值、影片延伸與角色一致性。


  

**[Genie 4](/docs/models/genie-4/)**

即時串流可操控的 24 fps 互動世界，並同步 48 kHz 立體聲音訊，透過 WebRTC 與 WebSockets 傳輸。


  

**[Gemini 3 Flash](/docs/models/gemini-3-flash-preview/)**

以遠低於大型模型的成本，提供足以媲美前沿等級的效能。


  

**[Gemini 3.5 Live Translate](/docs/models/gemini-3.5-live-translate-preview/)**

低延遲的即時語音對語音翻譯模型，支援 70 多種語言。


  

**[Gemini 3.1 Flash Live](/docs/models/gemini-3.1-flash-live-preview/)**

舊版 Live API 預覽模型。建議更新至 Gemini 3.8 Live。


  

**[Gemini 3.1 Flash TTS](/docs/models/gemini-3.1-flash-tts-preview/)**

舊版 TTS 預覽模型。建議更新至 Gemini 3.8 Flash TTS 或 Gemini 3.8 Flash-Lite TTS。

## 模型版本命名模式 {#model-versions}

Gemini 模型提供*穩定版*、*預覽版*、*最新版*或*實驗版*等版本。


!!! note " "

      注意：以下清單指的是截至 2025 年 9 月的模型字串命名慣例。在此之前發布的模型可能採用不同的命名慣例；若使用較舊的模型，請以確切的模型字串為準。


### 穩定版 {#stable}

指向特定的穩定模型。穩定模型通常不會變更。多數正式環境應用程式應使用特定的穩定模型。

例如：`gemini-3.6-flash`。

### 預覽版 {#preview}

指向可供正式環境使用的預覽模型。預覽模型通常會啟用計費，速率限制可能較嚴格，並會在至少提前 2 週通知的情況下淘汰。

例如：`gemini-2.5-flash-preview-09-2025`。

### 最新版 {#latest}

指向特定模型變體的最新版本，可以是穩定版、預覽版或實驗版。此別名會在該模型變體每次發布新版本時熱抽換。在最新版背後的版本變更前，會透過電子郵件提供 **2 週通知**。

例如：`gemini-flash-latest`。

### 實驗版 {#experimental}

指向實驗模型，通常不適合正式環境使用，速率限制也較嚴格。我們發布實驗模型，是為了蒐集回饋，並讓開發者能快速取得我們的最新更新。

實驗模型並不穩定，模型端點的可用性可能變更。
