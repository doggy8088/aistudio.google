# Gemini 3.1 Flash TTS (text-to-speech) preview


!!! note " "

      `gemini-3.1-flash-tts-preview` 是舊版預覽模型。對於新工作負載與正式環境
      工作負載，請遷移至
      [Gemini 3.8 Flash TTS](/docs/models/gemini-3.8-flash-tts/)
      (`gemini-3.8-flash-tts`) 或
      [Gemini 3.8 Flash-Lite TTS](/docs/models/gemini-3.8-flash-lite-tts/)
      (`gemini-3.8-flash-lite-tts`)。請參閱
      [遷移指南](/docs/speech-generation/#migration)。


Gemini 3.1 Flash TTS Preview 模型提供強大、低延遲的語音生成，輸出自然，並支援可引導的提示詞與富表現力的音訊標籤，可精確控制旁白。

[在 Google AI Studio 中試用](https://aistudio.google.com?model=gemini-3.1-flash-tts-preview)

## 文件 {#documentation}

Gemini 3.1 Flash TTS Preview 模型導入了富表現力的 [音訊標籤](/docs/speech-generation/#controllable)
來控制旁白，並在自然度、可控性與多語言能力方面全面提升。

請參閱 [文字轉語音](/docs/speech-generation/) 指南，瞭解功能與能力的完整說明。
