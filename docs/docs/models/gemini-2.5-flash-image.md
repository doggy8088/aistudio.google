# Gemini 2.5 Flash 圖片（Nano Banana）

我們最適合高速視覺創作的引擎，具備頂尖的速度與效率。Gemini 2.5 Flash Image 又稱為 Nano Banana，最適合大量生成、對話式圖片編輯，以及需要原生多模態理解的低延遲創意工作流程。
