# Deep Research 預覽版

功能強大的代理型研究工具，專為自主、多步驟的調查設計，能將複雜資訊綜整為附引用的完整報告。此模型支援協作規劃、視覺化、MCP 伺服器與 File Search，並提供兩個版本：著重速度與效率的 Deep Research，以及追求極致完整度的 Deep Research Max。

## 文件 {#documentation}

請造訪 [Deep Research](/docs/deep-research/) 頁面，查看功能與能力的完整說明。
