# Antigravity 預覽版

功能強大的通用型代管代理，專為自主、多步驟的工作流程設計。此模型可在 Google 代管的安全隔離 Linux 沙箱中進行規劃、推理、執行程式碼、管理檔案並搜尋網路。

2026 年 9 月發布的版本（`antigravity-preview-09-2026`）升級了執行階段框架，改善提示詞快取、加入原生程式碼搜尋工具，並提供高效率的行範圍檔案編輯功能。
