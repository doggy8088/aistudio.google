# Gemini 3.7 Flash


!!! note " "

       **已淘汰：** Gemini 3.7 Flash
      （`gemini-3.7-flash`）已淘汰，並由
      [Gemini 3.8 Flash（`gemini-3.8-flash`）](/docs/latest-model/) 取代。它已無法
      在 Google AI Studio 中選取，發送至
      `gemini-3.7-flash` 的 API 要求會自動導向 `gemini-3.8-flash`。


Gemini 3.7 Flash 是 Gemini 3 系列中原生多模態推理模型的上一代版本，
現已由 [Gemini 3.8 Flash](/docs/latest-model/) 取代。
