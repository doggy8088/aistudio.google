# Gemini 2.5 Flash Live 預覽版

Live API 讓 Gemini 2.5 Flash 能進行低延遲、即時的語音與影片互動。它會處理連續的音訊、影片或文字串流，即時給出自然真人的語音回應，為您的使用者帶來自然的對話體驗。

[在 Google AI Studio 中試用](https://aistudio.google.com?model=gemini-2.5-flash-native-audio-preview-12-2025)

請參閱 [Live API](/docs/live-api/) 指南，查看功能與能力的完整說明。
