# Veo 2.0


!!! warning " "

      此模型已於 **2026 年 6 月 30 日**[關閉](/docs/deprecations/)；請移轉至 [Gemini Omni Flash](/docs/models/gemini-omni-flash/)（`gemini-omni-1.2-flash`），或透過 [Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/veo/3-1-generate) 提供的 GA 模型，以免服務中斷。


這是我們穩健可靠的穩定版影片生成模型，為可投入正式環境的工作流程提供一致的效能。Veo 2.0 最適合標準 1080p 內容製作、社群媒體素材，以及著重角色一致性可靠、生成速度可預測且低於一秒的大量影片任務。
