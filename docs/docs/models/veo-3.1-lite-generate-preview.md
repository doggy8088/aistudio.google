# Veo 3.1 Lite 預覽版


!!! warning " "

       `veo-3.1-lite-generate-preview` 已於
      **2026 年 10 月 22 日**[關閉](/docs/deprecations/)；請移轉至
      [Gemini Omni Flash](/docs/models/gemini-omni-flash/)（`gemini-omni-1.2-flash`），或透過
      [Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/veo/3-1-generate)
      提供的 GA 模型，以免服務中斷。 


Veo 3.1 Lite Preview 是以開發者為優先的高效率影片模型，提供高擬真的影片生成、編輯與電影級控制。它運用頂尖的 Veo 3.1 模型，透過可擴充、可程式化的介面，讓創作者與企業也能使用專業級影片 AI，藉此普及這項技術。

## 文件 {#documentation}

如需完整的功能與能力說明，請造訪[影片生成](/docs/video/)頁面。請注意，Veo 3.1 Lite Preview 不支援 [4K 輸出](/docs/veo/#resolution)或[延伸功能](/docs/veo/#extending-veo-videos)。

## veo-3.1-lite-generate-preview {#veo-31-lite-generate-preview}


| 屬性 | 說明 |
| --- | --- |
| 模型代碼 | **Gemini API** `veo-3.1-lite-generate-preview` |
| 支援的資料類型 | **輸入** 文字、圖片 **輸出** 含音訊的影片 |
| 限制 | **文字輸入** 1,024 tokens **輸出影片** 1 部 |
| 最近更新 | 2026 年 3 月 |
