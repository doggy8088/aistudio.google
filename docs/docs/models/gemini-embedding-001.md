# Gemini Embedding 模型

這是專為高維度向量表示打造的引擎，能有效率地將文字與圖片對應為數值。Gemini Embedding 模型最適合語意搜尋、文件檢索與推薦系統，這類應用需要在大型資料集上進行快速且可擴充的相似度計算。

## 文件 {#documentation}

如需功能與能力的完整說明，請參閱 [Embeddings](/docs/embeddings/) 頁面。
