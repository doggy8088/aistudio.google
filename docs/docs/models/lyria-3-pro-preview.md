# Lyria 3 Pro 預覽版

Lyria 3 Pro Preview 是 Google 的旗艦音樂生成模型，專為生成結構連貫複雜的完整歌曲而最佳化，包含多段主歌、副歌與橋段。它可從文字提示詞或圖片輸入生成高品質的 48kHz 立體聲音訊。

[在 Google AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=lyria-3-pro-preview)
