# Gemini 3.5 Flash


!!! note " "

       **已淘汰**：Gemini 3.5 Flash
      (`gemini-3.5-flash`) 已淘汰，並由
      [Gemini 3.6 Flash (`gemini-3.6-flash`)](/docs/models/gemini-3.6-flash/) 取代。它已無法
      在 Google AI Studio 中選取，傳送至
      `gemini-3.5-flash` 的 API 請求會自動路由至 `gemini-3.6-flash`。請將
      模型字串更新為 `gemini-3.6-flash`（或
      [Gemini 3.8 Flash](/docs/models/gemini-3.8-flash/)）。


Gemini 3.5 Flash 是已淘汰的上一代 Flash 模型，提供持續的前沿級智慧，針對真實世界任務最佳化，同時具備更快的速度與更低的成本。
