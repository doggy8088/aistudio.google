# Gemini Robotics ER 2 串流

Gemini Robotics ER 2 Streaming 是專為機器人技術設計的視覺語言模型（VLM），透過 Live API 為即時文字串流最佳化。它接受文字、圖片、影片與音訊輸入，並支援具備函式呼叫的雙向串流。

[在 Google AI Studio 中試用](https://aistudio.google.com/prompts/new_chat?model=gemini-robotics-er-2-streaming-preview)

## 文件

如需完整的功能與能力說明，請造訪[機器人技術 Live API](/docs/robotics-streaming/)頁面。
