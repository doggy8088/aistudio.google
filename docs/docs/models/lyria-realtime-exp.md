# Lyria RealTime 實驗版

這是專為高擬真音樂合成打造的實驗性引擎，提供生成與轉換音訊內容的創新能力。Lyria RealTime 最適合 AI 輔助作曲、獨特的器樂生成，以及需要深度掌控旋律與節奏、且不含人聲的創意音訊工作流程。

[試用 Lyria RealTime](https://deepmind.google/models/lyria/lyria-realtime/)

## 文件 {#documentation}

如需完整的功能與能力說明，請造訪[即時音樂生成](/docs/realtime-music-generation/)頁面。

## lyria-realtime-exp {#lyria-realtime-exp}


| 屬性 | 說明 |
| --- | --- |
| 模型代碼 | **Gemini API** `lyria-realtime-exp` |
| 支援的資料類型 | **輸入** 文字（加權提示詞） **輸出** 音訊（原始 16 位元 PCM） |
| 串流限制 | **取樣率** 48kHz（立體聲） **控制延遲** 最長 2 秒 |
| 版本 | 如需詳細資訊，請參閱[模型版本命名模式](/docs/models/#model-versions)。實驗版：`lyria-realtime-exp` |
| 最近更新 | 2025 年 5 月 |
