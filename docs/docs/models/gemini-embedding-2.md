# Gemini Embedding 2 模型

這是我們的首款多模態嵌入模型，能有效率地將文字、圖片、影片、音訊與 PDF 對應到單一統一的嵌入空間。Gemini Embedding 2 模型最適合跨模態語意搜尋、文件檢索與推薦系統，這類應用需要在大型多模態資料集上進行快速且可擴充的相似度計算。

## 文件 {#documentation}

如需功能與能力的完整說明，請參閱 [Embeddings](/docs/embeddings/) 頁面。
