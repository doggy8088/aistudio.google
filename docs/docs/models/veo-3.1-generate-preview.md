# Veo 3.1


!!! warning " "

       `veo-3.1-generate-preview` 與
      `veo-3.1-fast-generate-preview` 已於
      **2026 年 10 月 22 日**[關閉](/docs/deprecations/)；請移轉至
      [Gemini Omni Flash](/docs/models/gemini-omni-flash/)（`gemini-omni-1.2-flash`），或透過
      [Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/veo/3-1-generate)
      提供的 GA 模型，以免服務中斷。 


這是專為高階創意敘事與實驗性影片製作設計的頂尖電影級引擎。Veo 3.1 最適合專業級 4K 輸出、原生同步音訊生成，以及需要最高水準時間一致性與藝術控制的複雜鏡頭運動。

## veo-3.1-generate-preview {#veo-31-generate-preview}


| 屬性 | 說明 |
| --- | --- |
| 模型代碼 | **Gemini API** `veo-3.1-generate-preview` `veo-3.1-fast-generate-preview` |
