# Deep Research Max 預覽版

自動化情境蒐集與綜整的極致完整度。Deep Research Max 專為長時間執行、攸關準確性的調查而最佳化，能從數百個公開網路來源與私人工作區資料中綜整複雜資訊，產出附引用的完整報告。它支援協作規劃、視覺化、MCP 伺服器與 File Search。
