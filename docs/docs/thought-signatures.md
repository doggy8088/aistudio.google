# 思考簽章

Interactions API 在 API 層級管理推理流程，讓思考簽章的操作變得更簡單。若要進一步了解如何設定模型思考、管理無狀態的思考步驟，以及檢視摘要，請參閱 [Gemini 思考](/docs/thinking/#signatures) 指南。

使用 Interactions API 時，你不需要手動擷取或傳遞個別內容部分的簽章。API 主要透過以下兩種方式簡化簽章管理：

* **自動狀態管理：** 在有狀態模式（`store: true`）下，伺服器會自動管理對話上下文，儲存並在各輪次之間傳遞思考簽章，你不需要自行追蹤。
* **專屬思考步驟：** 在無狀態模式下，內部推理會被隔離到專屬的 `thought` 步驟中，這些步驟位於 `steps` 陣列內。簽章會完整保留在這些步驟內，不會附加到使用者輸入、模型文字輸出或函式呼叫上。
