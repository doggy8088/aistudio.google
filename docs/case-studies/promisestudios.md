# 以 Gemini API 開創電影製作的新浪潮

Gemini API，連同 Veo 2 等開創性的生成式影片模型，不只是創意工具組的漸進式更新，更是說故事新時代的開端。[Promise](http://www.promisestudios.com/) 是一家富有遠見、GenAI 原生的工作室，正站在這場變革的最前線。透過運用 Gemini 2.5 Pro Preview 的協作能力與 Veo 2 的視覺實力，Promise 正重新想像從劇本到銀幕的電影製作工作流程，讓旗下藝術家能探索未曾涉足的電影領域。

## 強化電影創作流程

Promise 創立的信念是：GenAI 能協助電影人把雄心勃勃的故事化為現實。這家工作室正把 AI 深度整合進電影創作流程，讓工作流程比以往更敏捷、更有洞察力、視覺上也更動態。對 Promise 而言，Gemini 2.5 Pro Preview 正在放大人類的藝術造詣，扮演創意協作者的角色。它能協助分析人類撰寫的劇本以獲得更深的洞察、協助生成動態分鏡，並為 Veo 2 的視覺處理提供上下文，讓藝術家能快速迭代，邁向新穎的電影形式。讓我們看看 Promise 如何為這些整合開發原型：**深入劇本分析**：Gemini 2.5 Pro Preview 能進行細膩的劇本分析，辨識微妙的主題、描繪角色弧線，並建議視覺說故事的強化方式。**動態 AI 輔助分鏡**：Promise 的導演上傳手繪角色美術圖，並結合文字場景描述。接著 Gemini 2.5 能快速建立動態分鏡。**情境感知視覺處理**：Gemini 2.5 能把劇本分析得出的豐富上下文提供給 Veo。接著再以提示詞引導 Veo，生成與故事核心相符的影片輸出（預覽、VFX 概念、氛圍短片）。

## 開啟創意速度與電影表現力

雖然開發仍在進行中，Gemini 2.5 與 Veo 整合進 Promise 專有的製作工作流程軟體 MUSE，已展現推動電影製作的強大潛力：**加速創意發想**：AI 工具讓電影人能更快探索創意方向。**強化藝術掌控與迭代**：快速將想法視覺化，讓藝術家能迭代並完善其願景。**賦能更精簡的製作**：使用 AI 處理繁瑣的任務，釋放人類人才專注於故事本身。

> 「在 Promise，我們對能擴展創意可能性的工具感到興奮。Gemini 2.5 Pro Preview 與 Veo 2 協助我們的說故事者更快地從概念走向創作。這不是為了走捷徑或取代電影人——而是協助他們夢想得更大，並把故事化為現實。」

Jamie Byrne，Promise 總裁暨共同創辦人

Promise 率先整合 Gemini 2.5 Pro Preview 與 Veo 2，展現了 AI 協助重塑電影製作、並革新生成式 AI 時代工作室定義的深遠潛力。這次合作預示著一個未來：說故事者將擁有能跟上其想像力的工具。若想進一步了解如何使用 Gemini API 建置，請造訪 [Gemini API 文件](/docs/)，並在 [Google AI Studio](https://aistudio.google.com/) 中開始使用。Promise 是 [Google 的 AI Futures Fund](https://labs.google/aifuturesfund) 的參與者，該基金投資並與打造 AI 未來的雄心新創公司合作。
