# Shopify 以 Live API 驅動的多模態 AI 助理 Sidekick 協助商家致勝

[Shopify](https://play.google.com/store/apps/details?id=com.shopify.mobile) 是領先的全球商務平台，提供創立、擴展與行銷任何規模零售事業所需的基本基礎設施。為了持續改善商家的體驗，Shopify 團隊希望提供個人化、深入的助理，幫助 175 多個國家的數百萬商家創立並擴展事業。為此，他們開發了 Sidekick，一個設計來與商家在從設計到分析的各方面合作的 AI 助理。透過整合 [Live API](https://ai.google.dev/gemini-api/docs/live) 的語音與影片處理，Sidekick 是一個互動、能幹的商務助理，能即時提供協助，往往是在商家最艱難的時期。

## Sidekick：能幹的商務助理，協助商家高效率工作

Shopify 團隊希望 Sidekick 能將商務知識與商家的獨特需求無縫連結。在語音模式下，Sidekick 可以透過工具協助商家瀏覽 Shopify 管理後台、搜尋商店資源、調取其商店績效的分析，以及其他操作。它甚至能透過螢幕分享功能，協助排除管理後台之外的問題。

透過將複雜推理與語音驅動的互動結合，Sidekick 在遠離辦公桌時也能提供強健的支援——這對經常在外奔波、在倉庫開會或雙手忙碌的商家至關重要。

## 以 Live API 實現對話式協助

Sidekick 團隊使用 Gemini 2.5 Flash Native Audio 與 Live API 處理音訊，並以低延遲輸出逼真自然的語音。對話必須感覺反應靈敏，因為對話流暢度的中斷可能毀掉使用者體驗，並讓人打退堂鼓。團隊調整了提示訊號、語氣與發言輪替——機器人何時應該插話、應該多積極地發言——讓互動感覺更自然。這些語音與影片功能幫助打破了人們對簡單聊天機器人的預期，避免了許多 AI 助理的陷阱。「使用者在使用 Sidekick 不到一分鐘後，常常會忘記自己在跟 AI 說話，在某些情況下，甚至在長談後向機器人道謝，」產品副總裁 David Wurtz 表示。

## 打造整合平台以規模化生產力

打造一個感覺既能幹又善於對話的 AI 助理，是一項反覆迭代的工作。Shopify 團隊僅用三週，就從在 [Google AI Studio](https://ai.google.dev/gemini-api/docs/live) 中以 Gemini 模型進行原型開發，進展到在 [Vertex AI](https://console.cloud.google.com/vertex-ai/studio/multimodal-live) 上與真實使用者測試這項功能。從行銷到營運，團隊始終在尋求以其[整合平台](https://www.shopify.com/magic)幫助商家擴展事業。Wurtz 表示：「這是成為創業家的激動人心的時代。像 Gemini 所提供的這類全新 AI 能力，讓我們的商家有能力致勝。」
