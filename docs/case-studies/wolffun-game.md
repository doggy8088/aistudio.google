# Wolffun Game Studio 運用 Gemini 2.5 Flash Image 與 2.5 Pro 加速 PvP 遊戲開發

[Wolffun Game Studio](https://www.wolffungame.com/) 成立於 2014 年，已成為行動線上 PvP 遊戲的先驅。從早期的熱門作品——區塊鏈現象級遊戲 Thetan Arena（吸引超過 3,000 萬名玩家），到其最新的 1 對 1 射箭對戰遊戲 Thetan Immortal，Wolffun 不斷為全球玩家拓展競技遊戲的邊界。Wolffun 選擇 Gemini API，看中其多元的模型家族，使用 Gemini 2.5 Pro 與 2.5 Flash Image，透過減少程式碼審查時間與提升創意產出，協助加速開發週期。

## 從遊戲邏輯到對話：以 Gemini 2.5 Pro 打造遊戲體驗

遊戲開發需要在快速迭代、技術複雜度與創意卓越之間精細拿捏。傳統瓶頸——從耗時的程式碼審查、繁重的技術研究，到重複性的內容生成——都可能拖慢進度，讓寶貴的開發者時間無法投入創新。Wolffun 團隊運用 Gemini 2.5 Pro 先進的長上下文推理能力於：**原始碼分析**：團隊建置了一個自動化的 GitHub bot，能分析整個程式碼庫，建議著色器最佳化並重構舊有系統 **遊戲設計與平衡**：模型能建立複雜的文件與平衡公式，分析歷史玩家對戰資料以計算 bot 難度曲線，並為遊戲機制生成概念 **工程任務**：模型能自動化高層次的工程任務並為既有程式碼除錯，不只是簡單的程式碼補全 **故事開發與在地化**：模型能以 8 種語言生成豐富的背景故事與對話，並追蹤文化細微差異，讓傳達更準確。

![Wolffun 團隊使用整合了 Gemini 模型的專有工具，包括中繼資料工具與自動化 GitHub bot。](https://www.gstatic.com/aistudio/case_studies/wolffun/wolffun-inline-small.jpg)

自動化審查工具協助將初階開發者的程式碼審查時間減少 50%，資深開發者更減少達 90%，讓首席工程師能專注於架構與創新。像計算難度調整公式這類複雜任務，過去需要數天的手動計算，現在由 2.5 Pro 在幾分鐘內處理完成。

> 「Gemini 2.5 Pro 在需要複雜推理、程式設計與問題解決的任務上的表現，展現了明顯的優勢。對遊戲工作室而言，能有效率地處理效能最佳化與複雜遊戲邏輯生成等任務，是決定性的優勢。」

— Nguyen Dinh Khanh，Wolffun Game 執行長

## 使用 Gemini 2.5 Flash Image 生成概念美術圖

除了程式碼，Wolffun 也使用 Gemini 2.5 Flash Image 進行快速的視覺腦力激盪與素材創作。團隊指出，整合這個模型讓效率提升 40%，橫幅產量提升 35-40%，加速了行銷活動的上市時間。

![Gemini 2.5 Flash Image 根據參考圖片生成新的角色美術圖。](https://www.gstatic.com/aistudio/case_studies/wolffun/wolffun-demo.gif)

團隊很讚賞「Gemini 2.5 Flash 與 2.5 Flash-Lite 等模型的供應，讓我們能靈活地為玩家支援等大量任務，選擇效能與成本之間的適當平衡，使我們的 AI 整合在財務上可持續。」

## 驅動次世代個人化遊戲

展望未來，Wolffun 將 Gemini 模型視為高度個人化遊戲體驗的基礎技術。他們也計畫建置 AI 生成內容管線，根據玩家近期的動作，即時建立個人化的任務或遊戲內活動，為每位玩家帶來獨一無二的遊戲世界。Wolffun 的成功，凸顯了 AI 協助革新遊戲開發的巨大潛力，讓團隊能建置得更快、更自由地創新，最終為全球玩家帶來更引人入勝的體驗。
