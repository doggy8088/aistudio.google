# 以 Gemini API 塑造互動式 3D 的未來

## 以 Gemini API 與 Spline 打造多維度設計的未來

Gemini API 不只是改良數位工具；它正從根本上重塑我們創造數位世界並與之互動的方式。Spline 是率先將即時創作帶入瀏覽器的開創性協作 3D 設計工具，如今再次突破界限。Spline 現在將 Gemini 2.5 Pro Preview 的功能與其全新的畫布編輯器 Hana 整合，讓使用者能輕鬆地直接從文字描述產生完整的互動式 3D 與 2D 體驗，開啟協作創作的新時代。

## 簡化複雜的互動式設計

打造引人入勝、可直接用於正式產品的 2D 與 3D 互動體驗，傳統上需要複雜且高度技術性的工作流程，並要求專業技能與大量時間。Spline 的目標是徹底簡化這個流程，讓互動內容的創作更快速、更具協作性，並讓更多創作者都能直接在瀏覽器中完成。

## Spline 內幕：Gemini 2.5 Pro Preview 驅動全新的 Hana 編輯器

Spline 全新的 Hana 編輯器旨在簡化互動內容的創作流程。為此，Spline 正運用 Gemini 2.5 進行原型開發，引入開創性的文字轉體驗功能。目標是讓由 Gemini 2.5 強力驅動的 Hana 編輯器，徹底改變 2D/3D 環境與互動元素的產生方式：**AI 驅動的體驗產生**：原型開發的重點是讓使用者只需描述他們想像的元素、場景情境、著色器、互動性，甚至遊戲機制——例如「一款復古街機遊戲，玩家操控太空船躲避小行星，並有計分器」。**產生互動邏輯**：Spline 正在探索運用 Gemini 2.5 解讀這些提示詞，協助在 Hana 的引擎中產生底層的互動邏輯。這將讓創作者能運用 AI 快速製作體驗原型，再使用 Hana 熟悉的設計工具協作精煉，打造可直接用於正式產品的內容。

## 釋放創造力、協作與可及性

Spline 預期，將 Gemini 2.5 Pro Preview 整合進 Hana 編輯器，將在幾個重要面向重新定義創作版圖：**讓創作普及化**：讓使用者能從文字產生互動式 2D/3D 場景，可大幅降低技術門檻，讓更多人能更快地創作精緻的互動內容。**加速原型製作與迭代**：有機會將創作複雜體驗所需的時間從數週縮短到數分鐘或數小時，讓設計師與開發人員能以前所未有的速度測試概念、反覆迭代並發揮創意探索。**強化協作工作流程**：由 Gemini 2.5 處理初始產生，團隊便能立即進入 Hana 中已建置完成、可互動的場景，協作進行精煉、敘事與細部互動設計，簡化製作流程。

## 展望未來

Spline 的願景是讓互動式 2D/3D 創作變得簡單，且能直接用於正式產品。由 Gemini 2.5 Pro Preview 驅動的 Hana 編輯器，是朝這個方向邁出的里程碑一步。Spline 創辦人 Alejandro Leon 表示：「在 Spline，我們的主要目標之一一直是消除 3D 設計流程中的阻力，賦能設計師。有了 Gemini 2.5 Pro Preview，我們不只是簡化工作流程；我們正在催生一種全新的範式，讓你豐富的想像力幾乎能即刻轉化為互動式 2D/3D 體驗。」「Hana 能接收提示詞描述並產生可協作、可互動的體驗，這是顛覆性的改變。我們很期待看到設計師以比以往更快、更協作的方式，打造完整的互動體驗、遊戲化內容、沉浸式敘事，以及更多可能。」Spline 在 Hana 編輯器中運用 Gemini 2.5 的開創性原型工作，展現了先進 AI 為所有人開啟精緻創作能力的變革潛力。這次合作象徵著我們朝向未來的一大躍進——在那個未來，任何人都能打造自己夢想中的互動式多維度體驗。準備好開始打造了嗎？立即探索 [Gemini API 文件](https://ai.google.dev/gemini-api)，並開始使用 [Google AI Studio](https://aistudio.google.com/)。Spline 是 [Google 的 AI Futures Fund](https://labs.google.aifulturesfund/) 的參與者，該基金投資並與雄心勃勃的新創公司合作，共同打造 AI 的下一步。
