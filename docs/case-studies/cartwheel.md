# Cartwheel 運用 Gemini API 推動角色動畫進展

## Cartwheel 運用 Gemini API 推動角色動畫進展

Cartwheel 站在次世代動畫的最前沿，提供一個以自然語言輸入（例如 "jump"、"salsa dance spin"）指揮角色動作的平台。這項創新改善了創作者為影片、遊戲、廣告與社群媒體製作動畫的方式。Cartwheel 整合 Imagen 3，實現直覺的文字轉角色設計，並運用 Gemini 2.5 Pro Preview 開發精密的動畫專用演算法、探索複雜的程式碼庫，並加速平台最佳化，讓使用者能擴展其創意敘事。

## 克服生成式 3D 動作的研發障礙

開發尖端的動畫平台，不只需要使用者友善的設計工具，還需要後端演算法的持續創新與高效率的程式碼庫管理。Cartwheel 面臨的挑戰包括：快速原型開發並實作複雜的動畫功能、為效能最佳化其龐大的程式碼庫，以及讓開發者能快速理解並貢獻於一個大型系統。他們需要一個強大的 AI 夥伴來為開發工作注入超強動力。

## Cartwheel 如何使用 Imagen 3 與 Gemini 2.5 Pro Preview

Cartwheel 運用 Gemini API 改善其面向使用者的創作管線，並協助其內部開發流程。**以 Imagen 3 進行 AI 驅動的角色構思**：Cartwheel 整合 Imagen 3 的文字轉圖片功能，讓創作者能使用文字提示詞，直接在平台內構思並生成獨特的角色視覺。這些自訂設計的角色可以用自然語言製作動畫，接著匯出為已完成骨骼綁定、可直接用於 Maya 或 Blender 等業界標準 3D 編輯軟體的成品，整合進專業製作環境。**以 Gemini 2.5 Pro Preview 協助研發與最佳化**：Cartwheel 團隊在內部使用 Gemini 2.5 Pro Preview 支援其工程與研究工作流程：**開發演算法**：運用 Gemini 2.5 Pro Preview 協助開發動畫專用功能，包括用於資料合成的動態模糊演算法、用於混合的拉普拉斯金字塔，以及用於編輯器內擺姿勢的自動 IK（反向運動學）。**程式碼探索與除錯**：團隊使用 Gemini 2.5 Pro Preview 探索複雜的程式碼庫、為新實驗生成想法，並協助高效率地除錯邊界情況，例如棘手的攝影機旋轉錯誤。**運用長上下文進行程式碼庫操作**：Gemini 2.5 Pro Preview 的長上下文功能被用來處理 Cartwheel 的整個程式碼庫。這讓開發者能例如將新的程式碼庫（如前端）帶入上下文中，協助新增功能，或就系統的架構與功能提出高層次的問題。

## 賦能動畫工作流程

透過使用 Gemini 2.5 Pro Preview 協助演算法開發、程式碼探索與除錯，Cartwheel 旨在強化其開發流程並加速平台最佳化。Imagen 3 的整合為使用者提供了一種精簡的方式，從文字生成角色視覺，而 Gemini 2.5 Pro Preview 則作為協助開發者打造底層技術的工具。這些整合支援 Cartwheel 的目標：讓動畫工作流程更快、更容易使用，例如：加速遊戲與影片的素材建立，讓團隊能專注於核心設計。促進高效率的行銷與社群媒體內容生成。
