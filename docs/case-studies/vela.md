# 以 Gemini API 變革創投：Vela Partners 如何運用 Google 搜尋接地獲得更深入、更快速的洞見

在攸關重大的創投世界裡，及早辨識出最有潛力的新創公司，需要篩選龐大的資料並做出迅速且明智的決策。領先的量化創投公司 [Vela Partners](http://vela.partners/) 正運用 Gemini API 徹底改變這個流程，以前所未有的速度與精準度，將投資的藝術轉化為資料驅動的科學。Vela Partners 不是一般的創投公司。他們以「快 100 倍、好 100 倍」為使命，自 2017 年起便採用 AI 優先策略，專門投資 AI 新創公司。為了達成這個目標，他們需要一個能跟上步調的 AI 平台。Gemini API，特別是搭配 Google 搜尋接地的 Gemini 2.0 Flash，提供了恰當的解決方案。

## Vela Partners 如何使用 Gemini API

Vela Partners 運用 Gemini API 驅動兩個關鍵工作流程：**以接地豐富新創公司檔案**：早期新創公司，尤其是源自開放原始碼專案的公司，在網路上的能見度往往極低。Vela 使用以 Google 搜尋接地的 Gemini 2.0 Flash 自動填補這些缺口。分析 GitHub 儲存庫時，Gemini 能找出貢獻者的關鍵細節——所在地、所屬單位、經歷——豐富 Vela 內部模型用來評估潛力的資料。Vela Partners 的 AI 工程師 Zakari Salifu 表示：「Gemini 與 Google 搜尋接地正是我們尋找已久的解決方案。」這項能力超越了該公司先前探索過的資源密集型多代理框架與先進分析技術（[SSFF](https://arxiv.org/abs/2405.19456) 與 [Founder-idea-fit](https://arxiv.org/abs/2312.12037#:~:text=This%20research%20introduces%20an%20innovative,ideas%20to%20enhance%20decision%2Dmaking)）。**以即時分析簡化盡職調查**：一旦辨識出潛在投資標的，深入的盡職調查便至關重要。Gemini API 透過 Vercel AI SDK 整合，能即時從新聞、社群媒體等來源取得資料，提供對公司及其市場的全面視角。

## Google 搜尋接地的「魔力」

在 Gemini API 出現之前，蒐集新創公司的全面資訊是一大瓶頸。普通合夥人暨技術長 Yigit Ihlamur 解釋：「我們投資的是最早期的新創公司與人才。在這個階段，資訊散落在網路各處。」Gemini API 的 Google 搜尋接地功能證明具有變革性的效果。透過將 Gemini 2.0 Flash 的回應以 Google 搜尋結果接地，Vela 大幅降低了幻覺的風險，並確保他們的分析奠基於最新、最可靠的公開資訊。相較於他們先前的內部解決方案，這是顛覆性的改變。

## 實現速度、準確度與成本效益

對 Vela 而言，Gemini API 提供了理想的平衡。雖然他們已開發出精密的專有方法，仍在尋求更有效率的解決方案。前端智慧工程師 Afriyie Samuel 指出：「我們需要一個更輕量、更快速、更具成本效益的深度公司分析版本。搭配接地的 Gemini 2.0 Flash 正是我們尋找的解決方案。」相較於其他模型，Gemini 2.0 Flash 在實體資料豐富化方面表現更出色，甚至超越 Vela 自家的內部技術。

## 拓展創投領域的 AI 前沿

Vela Partners 的分析速度與準確度已見顯著提升。展望未來，他們計畫進一步整合 Gemini API，探索用於盡職調查的研究功能與檔案擷取。他們給其他開發人員的建議是：「想想 Google 擅長什麼。Google 是搜尋技術無可爭議的領導者。開始使用搭配接地搜尋的 Gemini 2.0 Flash，並將結果品質與其他開箱即用的 LLM 比較。你將親身體驗它的魔力。」Vela Partners 的歷程顯示，Gemini API 不只是一項工具，更是一項策略優勢，賦予他們引領 AI 驅動的創投未來的能力。準備好開始打造了嗎？[探索 Gemini API 文件](https://ai.google.dev/gemini-api)。
