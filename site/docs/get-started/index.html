    開始使用¶

    本指南將帶你透過 Interactions API 開始使用 Gemini API。你將在不到一分鐘內完成第一次 API 呼叫，並探索文字生成、 多模態理解、圖片生成、結構化輸出、工具、函式呼叫、代理與背景執行。

    Interactions API 可透過 Python 與 JavaScript SDK 使用，也可以 透過 REST 呼叫。

    使用 AI 程式設計代理開發嗎？將這段設定提示詞複製到你的代理中，或 連接我們的 MCP 伺服器與技能，即時取得最新 文件。

    Set up my Gemini API project using the Interactions API and the latest models. Read https://aistudio.google.com/docs/get-started.md first (every page under https://aistudio.google.com/docs/ is available as Markdown when you add `.md`, or via https://aistudio.google.com/llms.txt).
1. Install `google-genai` (Python) or `@google/genai` (JS/TS) for this project.
2. Check `GEMINI_API_KEY`, or prompt me to create one at https://aistudio.google.com/apikey.
3. Ask if I want to add the `gemini-api-dev` skill and Docs MCP server from https://aistudio.google.com/docs/coding-agents.md.
4. When we are set up, run one `client.interactions.create` test call, show me the reply, and ask what I want to build.

    1. 取得 API 金鑰¶

    使用 Gemini API 需要 API 金鑰，用來驗證你的請求、強制執行安全限制， 並將用量記錄到你的帳戶。

    • Google AI Studio 會自動為新使用者建立專案與 API 金鑰。你可以從 API 金鑰頁面 複製金鑰。
    • 如需新的金鑰，在 AI Studio 中點選 Create API key，並依照對話框 指示新增一組金鑰與專案的配對。
    • 額外建立的專案，以及從 Google Cloud 匯入的專案，可能需要先完成 專案驗證，才能使用免費層級。

    Create a Gemini API Key

    將金鑰設定為環境變數：

    export GEMINI_API_KEY="YOUR_API_KEY"

    如需提高速率限制，請在 API 金鑰 頁面點選 Set up billing， 或參閱計費指南。

    2. 安裝 SDK 並發出第一次呼叫¶

    安裝 SDK，並以單一 API 呼叫生成文字。

    安裝 SDK：

    pip install -U google-genai

    初始化用戶端並發出請求：

    from google import genai

client = genai.Client()

interaction = client.interactions.create(
    model="gemini-4-hydrogen",
    input="Explain how AI works in a few words"
)
print(interaction.output_text)

    安裝 SDK：

    npm install @google/genai

    初始化用戶端並發出請求：

    import { GoogleGenAI } from "@google/genai";

  model: "gemini-4-hydrogen",

});

    }

        fmt.Println(*res.Interaction.OutputText)
    }
}

    3. 串流回應¶

    若想讓互動更流暢，可在回應生成時即時串流。每個 step.delta 事件都會 傳遞一段文字，讓你立即顯示。

    from google import genai

client = genai.Client()

stream = client.interactions.create(
    model="gemini-4-hydrogen",
    input="Explain how AI works",
    stream=True
)
for event in stream:
    print(event)

const stream = await ai.interactions.create({
  model: "gemini-4-hydrogen",
  input: "Explain how AI works",

for await (const event of stream) {

import com.google.genai.gaos.models.operations.CreateInteractionResponse;
import com.google.genai.gaos.utils.EventStream;

Client client = new Client();

CreateModelInteraction params =
    CreateModelInteraction.builder()
        .model(Model.of("gemini-4-hydrogen"))
        .input(InteractionsInput.of("Explain how AI works"))
        .stream(true)
        .build();

CreateInteractionResponse response =
    client.interactions.create(CreateInteractionRequestBody.of(params));

try (EventStream<InteractionSSEStreamEvent> stream = response.events()) {
  for (InteractionSSEStreamEvent event : stream) {
    System.out.println(event);
  }
}

    4. 多輪對話¶

    Interactions API 支援兩種多輪對話方式：

    • 有狀態（建議）：使用 previous_interaction_id 在伺服器端延續 對話。適合大多數聊天與代理工作流程，讓伺服器管理歷史記錄並最佳化 快取。
    • 無狀態：在用戶端管理對話歷史，在每次請求中傳入先前的所有輪次 （包括模型中間的思考與工具步驟）。

    傳入 previous_interaction_id 即可串連多次互動，完整的對話歷史 由伺服器為你管理。
