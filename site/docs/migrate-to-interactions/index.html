    遷移至 Interactions API¶

    本指南協助你從 generateContent API 遷移至 Interactions API。

    Interactions API 是使用 Gemini 開發的標準介面，針對 代理工作流程、伺服器端狀態管理，以及複雜的多模態、 多輪對話最佳化，同時也完整支援簡單的無狀態單輪 要求。雖然 generateContent 仍受到完整支援， 我們仍建議所有新開發工作都採用 Interactions API。

    使用程式設計代理自動完成遷移。 如果你使用的 程式設計代理支援技能（例如 Gemini CLI 或 Jules），請安裝 Gemini API 技能，並執行：

    /gemini-api-dev migrate my app to the interactions api

    該技能會套用本指南所述的 API 變更。

    為什麼要遷移？¶

    Interactions API 提供更結構化且更強大的方式，讓你使用 Gemini 進行開發：

    • 伺服器端歷史記錄管理：透過 previous_interaction_id 簡化多輪流程。伺服器預設啟用狀態保存（store=true）， 你也可以設定 store=false，改採無狀態行為。
    • 可觀察的執行步驟：具型別的步驟讓你輕鬆除錯複雜 流程，並為中間事件（例如思考過程或搜尋小工具）呈現 UI。
    • 專為代理工作流程打造：原生支援多步驟工具使用、 協調編排與複雜的推理流程，皆透過具型別的執行步驟實現。
    • 長時間執行與背景工作：支援將 Deep Think、Deep Research 等耗時作業卸載至背景行程執行，方法是使用 background=true。

    本節說明如何遷移簡單的文字生成要求。

    變更前（generateContent）¶

    generateContent API 為無狀態 API，會直接傳回回應。 其回應結構將輸出包裝在 candidates 清單中，每個候選項都包含 content，其中含有待剖析的 parts 清單。

    from google import genai

client = genai.Client()

response = client.models.generate_content(
    model="gemini-4-hydrogen", contents="Tell me a joke."
)
print(response.text)

  model: "gemini-4-hydrogen",
  contents: "Tell me a joke.",

    Interactions API 會傳回已儲存的互動資源，其中包含 steps 時間軸。你可以手動檢查 steps 陣列，找出中間 事件；不過 Google GenAI SDK 也在傳回的 Interaction 物件上 直接提供便利屬性，讓你存取最終輸出。

    最常用的便利屬性是 .output_text（String），它會 自動擷取並串連模型回應結尾處連續的 TextContent 區塊。這個屬性對簡單回應非常好用， 但不會包含先前被非文字內容（例如思考過程、圖片、 音訊或工具呼叫）隔開的文字區塊。若是複雜或交錯的 多模態回應，你必須改為手動逐一處理 steps。

client = genai.Client()

interaction = client.interactions.create(
    model="gemini-4-hydrogen", input="Tell me a joke."
)

print(interaction.output_text)

    多輪對話¶

    Interactions API 預設會儲存互動，藉此在伺服器端管理 多輪對話的狀態。

    變更前（generateContent）¶

    使用 generateContent 時，你必須透過 contents 陣列 或用戶端聊天輔助工具，手動管理對話歷史記錄。

    使用聊天輔助工具（建議）

    from google import genai

client = genai.Client()

chat = client.chats.create(model="gemini-4-hydrogen")
response1 = chat.send_message("Hi, my name is Phil.")
print(response1.text)

response2 = chat.send_message("What is my name?")
print(response2.text)

    手動管理歷史記錄

    from google import genai
from google.genai import types

client = genai.Client()

response = client.models.generate_content(
    model="gemini-4-hydrogen",
    contents=[
        types.Content(
            role="user", parts=[types.Part.from_text("Hi, my name is Phil.")]
        ),
        types.Content(
            role="model",
            parts=[types.Part.from_text("Hi Phil, how can I help you?")],
        ),
        types.Content(
            role="user", parts=[types.Part.from_text("What is my name?")]
        ),
    ],
)

    多模態生成¶

    生成文字以外的模態內容（例如圖片或音訊）時， 主要差異在於回應如何組織所生成的媒體內容。

    變更前（generateContent）¶

    使用 generateContent 時，回應會將生成的媒體直接放在候選項的 parts 中傳回，通常是以 inlineData 形式存放的 base64 資料。

    # Response structure concept
{
  "candidates": [
    {
      "content": {
        "parts": [
          {
            "text": "Here is your generated image:"
          },
          {
            "inlineData": {
              "mimeType": "image/jpeg",
              "data": "...base64..."
            }
          }
        ]
      }
    }
  ]
}

    變更後（Interactions API）¶

    使用 Interactions API 時，生成的媒體會以獨立項目的形式，出現在 content 陣列中，該陣列位於時間軸的 model_output 步驟內，維持互動的 時間順序。

    # Response structure concept
{
  "id": "int_123",
  "steps": [
    {
      "type": "model_output",
      "status": "done",
      "content": [
        {
          "type": "text",
          "text": "Here is your generated image:"
        },
        {
          "type": "image",
          "mime_type": "image/jpeg",
          "data": "...base64..." // Or a reference URL in future
        }
      ]
    }
  ]
}

    如此一來，回應的剖析方式便與輸入及文字輸出的處理方式保持一致 ——一切都是時間軸中的一個步驟。

    變更後（Interactions API）¶

    使用 Interactions API 時，伺服器端工具提供完整的時間軸透明度。 API 會將呼叫與結果記錄為獨立的執行 steps （google_search_call 與 google_search_result），清楚呈現模型 實際擷取了哪些資料。

    此外，API 會將引用內嵌於文中傳回。你不需要再從獨立的中繼資料 物件對應索引；model_output 步驟中的文字項目本身就含有 專屬的 annotations 陣列，直接連結至來源。

        if step.content[0].annotations:
            for anno in step.content[0].annotations:

Client client = new Client();

Map<String, Object> properties = new HashMap<>();

Map<String, Object> parameters = new HashMap<>();
parameters.put("type", "object");
parameters.put("properties", properties);
parameters.put("required", Arrays.asList("location"));

Function getWeatherTool =
    Function.builder()
        .name("get_weather")
        .description("Gets weather")
        .parameters(parameters)
        .build();

CreateModelInteraction request =
    CreateModelInteraction.builder()
        .model(Model.of("gemini-4-hydrogen"))
        .input(InteractionsInput.of("What's the weather in Boston?"))
        .tools(Arrays.asList(getWeatherTool))
        .stream(true)
        .build();

try (EventStream<InteractionSSEStreamEvent> stream =
    client.interactions.create(CreateInteractionRequestBody.of(request)).events()) {
  for (InteractionSSEStreamEvent streamEvent : stream) {
    if (streamEvent.data().isPresent()) {
      InteractionSSEEvent event = streamEvent.data().get();
      if (event instanceof StepStart) {
        StepStart stepStart = (StepStart) event;
        if (stepStart.step().isPresent() && stepStart.step().get() instanceof FunctionCallStep) {
          FunctionCallStep fcStep = (FunctionCallStep) stepStart.step().get();
          System.out.println("Calling: " + fcStep.name().orElse(""));
        }
      } else if (event instanceof StepDelta) {
        StepDelta stepDelta = (StepDelta) event;
        if (stepDelta.delta().isPresent()) {
          StepDeltaData delta = stepDelta.delta().get();
          if (delta instanceof ArgumentsDelta) {
            System.out.println("  args: " + ((ArgumentsDelta) delta).arguments().orElse(""));
          } else if (delta instanceof TextDelta) {
            System.out.print(((TextDelta) delta).text().orElse(""));
          }
        }
      } else if (event instanceof InteractionCompletedEvent) {
        System.out.println("\n--- Done ---");
      }
    }
  }
}

    package main

import (
    "context"
    "fmt"
    "log"

    "google.golang.org/genai"
    "google.golang.org/genai/interactions/models/interactions"
    "google.golang.org/genai/interactions/models/operations"
)

func main() {
    ctx := context.Background()
    client, err := genai.NewClient(ctx, nil)
    if err != nil {
        log.Fatal(err)
    }

    getWeatherTool := interactions.NewTool(interactions.Function{
        Name:        genai.Ptr("get_weather"),
        Description: genai.Ptr("Gets weather"),
        Parameters: map[string]any{
            "type": "object",
            "properties": map[string]any{
                "location": map[string]any{"type": "string"},
            },
            "required": []string{"location"},
        },
    })

    res, err := client.Interactions.Create(ctx, operations.CreateInteractionRequest{
        Body: operations.NewCreateInteractionRequestBody(interactions.CreateModelInteraction{
            Model:  interactions.Model("gemini-4-hydrogen"),
            Input:  interactions.NewInteractionsInput("What's the weather in Boston?"),
            Tools:  []interactions.Tool{getWeatherTool},
            Stream: genai.Ptr(true),
        }),
    })
    if err != nil {
        log.Fatal(err)
    }
    stream := res.InteractionSSEStreamEvent
    defer stream.Close()

    for stream.Next() {
        event := stream.Value()
        if stepStart := event.GetDataStepStart(); stepStart != nil {
            if fcStep := stepStart.GetStepFunctionCall(); fcStep != nil {
                fmt.Println("Calling:", fcStep.Name)
            }
        } else if stepDelta := event.GetDataStepDelta(); stepDelta != nil {
            if argsDelta := stepDelta.GetDeltaArgumentsDelta(); argsDelta != nil {
                fmt.Println("  args:", argsDelta.GetArguments())
            } else if textDelta := stepDelta.GetDeltaText(); textDelta != nil {
                fmt.Print(textDelta.GetText())
            }
        } else if event.GetDataInteractionCompleted() != nil {
            fmt.Println("\n--- Done ---")
        }
    }
    if err := stream.Err(); err != nil {
        log.Fatal(err)
    }
}
