    在 Gemini API 中使用 Veo 3.1 生成影片¶

    Gemini API 中的 Veo 3.1 Preview（veo-3.1-generate-preview、 veo-3.1-fast-generate-preview 與 veo-3.1-lite-generate-preview）已於 2026 年 10 月 22 日停止服務。為避免服務中斷，請遷移至 Gemini Omni Flash（gemini-omni-1.2-flash）， 或改用透過 Gemini Enterprise Agent Platform 提供的 GA 模型。

    如需瞭解影片理解功能，請參閱影片理解指南。

    Veo 3.1 是一款可生成 8 秒影片（720p、1080p 或 4k）並原生生成音訊的模型。你可以透過 Gemini API 以程式方式存取 這個模型。如需瞭解可用的 Veo 模型版本，請參閱模型版本一節。

    Veo 3.1 擅長多種視覺與電影風格，並導入了數項新功能：

    • 直向影片：可選擇橫向（16:9）或直向（9:16） 影片。
    • 影片延伸：延伸先前使用 Veo 生成的影片。
    • 指定影格生成：指定第一個與最後一個 影格來生成影片。
    • 以圖片引導：使用最多三張參考圖片來引導 生成影片的內容。

    如需瞭解如何為影片生成撰寫有效的文字提示詞， 請參閱 Veo 提示詞指南

      }
    ]
  }' | jq -r .name)

while true; do

  status_response=$(curl -s -H "x-goog-api-key: $GEMINI_API_KEY" "${BASE_URL}/${operation_name}")

  is_done=$(echo "${status_response}" | jq .done)

    使用參考圖片¶

    延伸 Veo 影片¶

    此功能僅適用於 Veo 3.1 與 Veo 3.1 Fast 模型，不適用於

    Veo 3.1 Lite。

    使用 Veo 3.1，可將先前以 Veo 生成的影片延伸 7 秒，最多可延伸 20 次。

    輸入影片的限制：

    • 僅限長度不超過 141 秒的 Veo 生成影片。
    • Gemini API 僅支援延伸 Veo 生成的影片。
    • 影片應來自先前的生成結果，例如 operation.response.generated_videos[0].video
    • 影片會儲存 2 天，但若影片被引用來進行延伸， 其 2 天的儲存計時器會重新計算。你只能延伸在過去兩天內生成 或被引用過的影片。
    • 輸入影片應具備特定的長度、長寬比與尺寸：
    • 長寬比：9:16 或 16:9
    • 解析度：720p
    • 影片長度：141 秒或更短

    延伸的輸出結果是將使用者輸入的影片與 生成的延伸影片合併而成的單一影片，長度最長可達 148 秒。

    限制¶

    • 多影片提示：目前不支援參照多部影片或跨多部影片進行推理。嘗試多影片提示可能導致模型效能下降或產生非預期的輸出。
    • 語言支援：完整支援英文（EN），但其他語言尚未經過評估，因此可能可用，但結果可能有所不同。
    • 要求延遲：最短 11 秒；最長 6 分鐘（尖峰時段）。
    • 地區限制：在 EU、UK、CH、MENA 地區，allow_adult 是 personGeneration 唯一允許的值。
    • 影片保留：生成的影片會在伺服器上儲存 2 天， 之後即會移除。若要保存本機副本，你必須在生成後 2 天內下載影片。延伸後的影片會視為新生成的 影片。
    • 浮水印：Veo 建立的影片會使用 SynthID 加上浮水印，這是我們用來為 AI 生成內容加上浮水印 並加以識別的工具。影片可透過 SynthID 驗證平台進行驗證。
    • 安全性：生成的影片會經過安全篩選器與 記憶檢查流程，有助於降低隱私、著作權與 偏見方面的風險。
    • 音訊錯誤：Veo 3.1 有時會因為安全篩選器或其他音訊處理問題， 而阻擋影片生成。若你的影片被阻擋而無法生成， 你不會被收費。

    安全篩選器¶

    Veo 在整個 Gemini 中套用安全篩選器，以協助確保 生成的影片與上傳的照片不含冒犯性內容。 違反我們的條款與指南的提示詞會被阻擋。

    提示詞撰寫基礎¶

    好的提示詞應具備描述性且清晰明確。若要充分發揮 Veo 的能力，先找出 你的核心構想，再透過加入關鍵字與修飾詞來精煉構想， 並將影片專用術語融入提示詞中。

    你的提示詞應包含以下元素：

    • 主體：你希望出現在影片中的物件、人物、動物或景色， 例如 cityscape、nature、vehicles 或 puppies。
    • 動作：主體正在做的事（例如 walking、running 或 turning their head）。
    • 風格：使用特定的電影 風格關鍵字來指定創意方向，例如 sci-fi、horror film、film noir，或動畫 風格如 cartoon。
    • 攝影機位置與運動：[Optional] 使用 aerial view、eye-level、top-down shot、 dolly shot 或 worms eye 等詞彙，控制攝影機的位置 與移動方式。
    • 構圖：[Optional] 鏡頭的取景方式，例如 wide shot、 close-up、single-shot 或 two-shot。
    • 焦點與鏡頭效果：[Optional] 使用 shallow focus、 deep focus、soft focus、macro lens 與 wide-angle lens 等詞彙，達成 特定的視覺效果。
    • 氛圍：[Optional] 色彩與光線如何為場景增添氣氛， 例如 blue tones、night 或 warm tones。

    撰寫提示詞的更多技巧¶

    • 使用描述性語言：使用形容詞與副詞，為 Veo 描繪出清晰的畫面。
    • 強化臉部細節：將 臉部細節指定為畫面的焦點，例如在 提示詞中使用 portrait 一詞。

    如需更完整的提示詞策略，請參閱提示詞設計簡介。

    為音訊撰寫提示詞¶

    你可以為 Veo 提供音效、環境噪音與對話的提示。 模型會捕捉這些提示的細微差別，生成同步的配樂。

    • 對話：使用引號標示特定的台詞。（範例："This must be the key," he murmured.）
    • 音效（SFX）：明確描述聲音。（範例：tires screeching loudly, engine roaring.）
    • 環境噪音：描述環境的聲音景觀。（範例：A faint, eerie hum resonates in the background.）
