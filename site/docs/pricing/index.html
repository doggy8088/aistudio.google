    Gemini Developer API 定價¶

    先以寬裕的額度免費開始建構，再透過預付與隨用隨付的定價擴展規模，支援您可投入生產環境的應用程式。若要比較各模型的推理深度、速度與成本取捨，請參閱選擇模型。

    免費

    適合剛開始使用 Gemini API 的開發人員與小型專案。

    • 僅能有限存取部分模型
    • 免費的輸入與輸出權杖
    • 可使用 Google AI Studio
    • 內容會用於改善我們的產品*

    免費開始使用

    付費

    適合需要更高用量與進階功能的生產應用程式。

    • 生產部署享有更高的速率限制
    • 可使用上下文快取
    • Batch API（成本降低 50%）
    • 可使用 Google 最先進的模型
    • 內容不會用於改善我們的產品*

    升級至付費版

    企業版

    適合企業部署，由 Gemini Enterprise Agent Platform 驅動。

    • 包含付費版的所有功能，並可額外選用：
    • 專屬支援管道
    • 進階安全性與法規遵循
    • 預配輸送量
    • 依用量提供量價折扣
    • ML ops、model garden 等更多功能
