    2026 年 11 月 19 日¶

    • Genie 4（models/genie-4）正式推出（GA）：推出 Genie 4（models/genie-4），於 Interactions API（v1beta）上實現即時互動世界生成，串流可操控的 24 fps 16:9 影片，並同步 48 kHz 立體聲音訊，透過 WebRTC 與 WebSockets 傳輸。以文字、 16:9 參考圖片或兩者播種世界，並以 WASD/方向鍵與工作階段中的文字事件即時操控。 付費層級的定價為每 100 萬個輸入 tokens $1.50、每 100 萬個文字輸出 tokens $9.00，以及每 100 萬個影片輸出 tokens $17.50（約 ~$0.10/sec，含立體聲音訊）；請參閱 使用 Genie 4 生成互動世界、Genie 4 提示詞與控制指南與 速率限制。

    • 工具擷取（預覽版）：Interactions API 現在可以搜尋你的工具程式庫，並按需載入函式結構描述， 因此大型工具集不再需要在每次請求時完整傳送。以 defer_loading: true 標記工具，並加入 {"type": "tool_search"} 工具，讓 Gemini 為你擷取結構描述，或設定 execution: "client" 以執行你自己的擷取邏輯。遠端 MCP 伺服器也支援 defer_loading。

      工具擷取適用於 Gemini 3.6 及更新模型，包括所有 Gemini 4 模型，於 Interactions API 中使用。請參閱 工具擷取指南。

    • 多模態檔案處理與切片：現在可以直接將 Microsoft Office 與 OpenDocument 檔案（Word、PowerPoint 與 Excel）直接傳給 Gemini API， 並在使用者提示詞與函式回應 中切片文件、試算表、影片與音訊。指定頁碼範圍、工作表分頁、儲存格範圍、 時間區間或內容圖層（例如頁面圖片、擷取的文字、公式或影片轉錄稿）， 只處理並支付你需要的內容。

      如需開始使用，請參閱文件理解、 影片理解 與音訊理解。
