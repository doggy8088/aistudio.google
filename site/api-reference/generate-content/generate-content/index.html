    產生內容¶

    POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent

    根據輸入的 GenerateContentRequest 產生模型回應。詳細用法請參閱文字生成指南。不同模型的輸入能力有所不同，微調模型亦然。詳情請參閱模型指南與微調指南。

    參數¶

    model：必填 string

    模型 ID，例如 gemini-2.5-flash。組成資源名稱 models/{model}。

    請求主體¶

    model：必填 string

    用於產生完成結果的 Model 名稱。格式：models/{model}。

    contents：必填 Content array

    與模型進行目前對話的內容。單輪查詢時為單一執行個體；多輪查詢（例如聊天）時，這是包含對話記錄與最新請求的重複欄位。

    systemInstruction：Content

    選填。開發人員設定的系統指令。目前僅支援文字。

    tools：Tool array

    選填。Tools 清單，Model 可用於產生下一個回應。Tool 是一段程式碼，讓系統能與外部系統互動，在 Model 的知識與範圍之外執行某個動作或一組動作。支援的 Tool 為 Function 與 code_execution。詳情請參閱函式呼叫與程式碼執行指南。

    toolConfig：ToolConfig 選填。請求中指定的任何 Tool 的工具設定。使用範例請參閱函式呼叫指南。
    functionCallingConfig：FunctionCallingConfig 選填。函式呼叫設定。
    mode：string enum 選填。指定函式呼叫的執行模式。若未指定，預設值為 AUTO。

    可能的值：

    • MODE_UNSPECIFIED：未指定的函式呼叫模式。不應使用此值。
    • AUTO：模型預設行為，由模型決定要預測函式呼叫或自然語言回應。
    • ANY：模型被限制為只能預測函式呼叫。若已設定 "allowed_function_names"，預測的函式呼叫將限於 "allowed_function_names" 中的任一個；否則預測的函式呼叫將是提供的 "function_declarations" 中的任一個。
    • NONE：模型不會預測任何函式呼叫。模型行為與未傳入任何函式宣告時相同。
    • VALIDATED：模型決定預測函式呼叫或自然語言回應，但會以受限解碼驗證函式呼叫。若已設定 "allowed_function_names"，預測的函式呼叫將限於 "allowed_function_names" 中的任一個；否則預測的函式呼叫將是提供的 "function_declarations" 中的任一個。

    allowedFunctionNames：string array

    選填。一組函式名稱，提供後會限制模型可呼叫的函式。僅應在 Mode 為 ANY 或 VALIDATED 時設定。函式名稱應與 [FunctionDeclaration.name] 相符。設定後，模型只會從允許的函式名稱中預測函式呼叫。

    retrievalConfig：RetrievalConfig 選填。擷取設定。
    latLng：LatLng 選填。使用者的位置。

    latitude：number

    以度為單位的緯度。必須介於 [-90.0, +90.0] 範圍內。

    longitude：number

    以度為單位的經度。必須介於 [-180.0, +180.0] 範圍內。

    languageCode：string

    選填。使用者的語言代碼。內容的語言代碼。使用 BCP47 定義的語言標籤。

    includeServerSideToolInvocations：boolean

    選填。若為 true，API 回應會在 Content 訊息中包含伺服器端工具呼叫與回應，讓用戶端能觀察伺服器的工具互動。

    safetySettings：SafetySetting array

    選填。用於封鎖不安全內容的專屬 SafetySetting 執行個體清單。此設定會強制套用於 GenerateContentRequest.contents 與 GenerateContentResponse.candidates。每個 SafetyCategory 類型不應有多於一個設定。API 會封鎖任何未達這些設定所定門檻的內容與回應。此清單會覆寫 safety_settings 中指定的每個 SafetyCategory 的預設設定。若清單中未提供 SafetySetting 供某個 SafetyCategory 使用，API 會使用該類別的預設安全設定。支援的危害類別為 HARM_CATEGORY_HATE_SPEECH、HARM_CATEGORY_SEXUALLY_EXPLICIT、HARM_CATEGORY_DANGEROUS_CONTENT、HARM_CATEGORY_HARASSMENT、HARM_CATEGORY_CIVIC_INTEGRITY、HARM_CATEGORY_JAILBREAK。可用安全設定的詳細資訊請參閱指南。另請參閱安全指南，了解如何將安全考量納入您的 AI 應用程式。

    generationConfig：GenerationConfig 選填。模型產生與輸出的設定選項。

    candidateCount：integer

    選填。要傳回的產生回應數量。若未設定，預設為 1。請注意，此設定不適用於前幾代模型（Gemini 1.0 系列）。

    stopSequences：string array

    選填。會停止輸出產生的字元序列集合（最多 5 個）。若指定，API 會在 stop_sequence 首次出現時停止。停止序列不會包含在回應中。

    maxOutputTokens：integer

    選填。回應候選中可包含的權杖數量上限。注意：預設值依模型而異，請參閱 Model.output_token_limit 屬性（屬於 Model，由 getModel 函式傳回）。

    temperature：number

    選填。控制輸出的隨機程度。注意：預設值依模型而異，請參閱 Model.temperature 屬性（屬於 Model，由 getModel 函式傳回）。值可介於 [0.0, 2.0]。此欄位在 Gemini 3.6 Flash 及更新的模型上不再支援，會被靜默忽略。

    topP：number

    選填。取樣時要考量的權杖累積機率上限。模型結合使用 Top-k 與 Top-p（nucleus）取樣。權杖會依其指派的機率排序，只考量最有可能的權杖。Top-k 取樣直接限制要考量的權杖數量上限，Nucleus 取樣則依累積機率限制權杖數量。注意：預設值依 Model 而異，由 Model.top_p 屬性指定，該屬性由 getModel 函式傳回。空的 top_k 屬性表示模型不套用 top-k 取樣，也不允許在請求上設定 top_k。此欄位在 Gemini 3.6 Flash 及更新的模型上不再支援，會被靜默忽略。

    topK：integer

    選填。取樣時要考量的權杖數量上限。Gemini 模型使用 Top-p（nucleus）取樣，或 Top-k 與 nucleus 取樣的組合。Top-k 取樣考量機率最高的 top_k 個權杖集合。使用 nucleus 取樣執行的模型不允許設定 top_k。注意：預設值依 Model 而異，由 Model.top_p 屬性指定，該屬性由 getModel 函式傳回。空的 top_k 屬性表示模型不套用 top-k 取樣，也不允許在請求上設定 top_k。此欄位在 Gemini 3.6 Flash 及更新的模型上不再支援，會被靜默忽略。

    seed：integer

    選填。解碼時使用的種子。若未設定，請求會使用隨機產生的種子。

    responseMimeType：string

    選填。產生的候選文字的 MIME 類型。支援的 MIME 類型為：text/plain：（預設）文字輸出。application/json：回應候選中的 JSON 回應。text/x.enum：回應候選中以字串形式表示的 ENUM 回應。所有支援的文字 MIME 類型清單請參閱文件。

    responseJsonSchema：object

    選填。內部細節。請改用 responseJsonSchema，不要使用此欄位。

    presencePenalty：number

    選填。若某個權杖已在回應中出現過，對下一個權杖的 logprobs 套用的存在懲罰。此懲罰是二元的開／關，不取決於權杖被使用的次數（第一次之後）。若要使用隨使用次數增加的懲罰，請使用 frequency_penalty。正值懲罰會降低使用已在回應中用過的權杖，擴大詞彙量；負值懲罰會鼓勵使用已在回應中用過的權杖，縮小詞彙量。

    frequencyPenalty：number

    選填。對下一個權杖的 logprobs 套用的頻率懲罰，會乘以每個權杖至今在回應中出現的次數。正值懲罰會依權杖被使用的次數比例降低其再次使用：權杖用得越多，模型就越難再次使用該權杖，進而擴大回應的詞彙量。注意：負值懲罰會鼓勵模型依權杖被使用的次數比例重複使用權杖。較小的負值會縮小回應的詞彙量；較大的負值會使模型開始重複某個常見權杖，直到達到 max_output_tokens 上限。

    responseLogprobs：boolean

    選填。若為 true，在回應中匯出 logprobs 結果。

    logprobs：integer

    選填。僅在 response_logprobs=True 時有效。此設定決定在每個解碼步驟要傳回的頂尖 logprobs 數量（包含所選候選），傳回於 Candidate.logprobs_result 中。數字必須介於 [0, 20] 範圍內。

    enableEnhancedCivicAnswers：boolean

    選填。啟用強化公民答覆。並非所有模型都提供此功能。

    資料模型¶

    Candidate¶

    由模型產生的回應候選。

    Properties：

    index：integer

    僅供輸出。候選在回應候選清單中的索引。

    content：Content

    僅供輸出。模型傳回的產生內容。

    finishReason：string enum 選填。僅供輸出。模型停止產生權杖的原因。若為空，表示模型尚未停止產生權杖。

    可能的值：

    • FINISH_REASON_UNSPECIFIED：預設值。此值未使用。
    • STOP：模型的自然停止點或提供的停止序列。
    • MAX_TOKENS：已達到請求中指定的權杖數量上限。
    • SAFETY：回應候選內容因安全原因被標記。
    • RECITATION：回應候選內容因重述原因被標記。
    • LANGUAGE：回應候選內容因使用不支援的語言而被標記。
    • OTHER：未知原因。
    • BLOCKLIST：權杖產生因內容包含禁用詞彙而停止。
    • PROHIBITED_CONTENT：權杖產生因可能包含禁止內容而停止。
    • SPII：權杖產生因內容可能包含敏感個人識別資訊（SPII）而停止。
    • MALFORMED_FUNCTION_CALL：模型產生的函式呼叫無效。
    • IMAGE_SAFETY：權杖產生因產生的圖片包含安全違規而停止。
    • IMAGE_PROHIBITED_CONTENT：圖片產生因產生的圖片含有其他禁止內容而停止。
    • IMAGE_OTHER：圖片產生因其他雜項問題而停止。
    • NO_IMAGE：模型預期應產生圖片，但未產生任何圖片。
    • IMAGE_RECITATION：圖片產生因重述而停止。
    • UNEXPECTED_TOOL_CALL：模型產生了工具呼叫，但請求中未啟用任何工具。
    • TOO_MANY_TOOL_CALLS：模型連續呼叫了太多工具，因此系統結束執行。
    • MISSING_THOUGHT_SIGNATURE：請求至少缺少一個思考簽章。
    • MALFORMED_RESPONSE：因回應格式錯誤而結束。

    Content¶

    包含訊息多部分內容的基礎結構化資料類型。

    Content 包含一個 role 欄位，指定 Content 的產生者；以及一個 parts 欄位，包含構成訊息輪次內容的多部分資料。

    Properties：

    parts：Part array 構成單一訊息的有序 Parts。各部分可能有不同的 MIME 類型。
    data：Union type

    Union 欄位 data 只能是下列其中之一：

    text：string

    行內文字。

    inlineData：Blob 行內媒體位元組。

    mimeType：string

    來源資料的 IANA 標準 MIME 類型。支援類型的範例：

    • 圖片： image/png, image/jpeg, image/jpg, image/webp, image/heic, image/heif, image/gif, image/avif
    • Audio: audio/*, video/audio/s16le, video/audio/wav
    • Video: video/*
    • 文字： text/plain, text/html, text/css, text/javascript, text/x-typescript, text/csv, text/markdown, text/x-python, text/xml, text/rtf, video/text/timestamp
    • 應用程式： application/x-javascript, application/x-typescript, application/x-python-code, application/json, application/x-ipynb+json, application/rtf, application/pdf For additional context, see Supported file formats.

    data：string

    媒體格式的原始位元組。

    displayName：string

    選填。指定用來向模型指稱此 blob 的名稱（例如 "my_blob.png"）。當 verbalization_mode 設為 REFERENCE_ONLY 時，用作 blob 參考識別碼。

    functionCall：FunctionCall 模型傳回的預測 FunctionCall，包含一個表示 FunctionDeclaration.name 的字串，以及引數與其值。

    name：必填 string

    要呼叫的函式名稱。必須為 a-z、A-Z、0-9，或包含底線與連字號，長度上限為 128。

    id：string

    選填。函式呼叫的專屬識別碼。若有填入，用戶端應執行該 function_call 並以相符的 id 傳回回應。

    args：object

    選填。JSON 物件格式的函式參數與值。

    functionResponse：FunctionResponse FunctionCall 的結果輸出，包含一個表示 FunctionDeclaration.name 的字串，以及一個包含函式任何輸出的結構化 JSON 物件，用作模型的上下文。

    name：必填 string

    要呼叫的函式名稱。必須為 a-z、A-Z、0-9，或包含底線與連字號，長度上限為 128。

    id：string

    選填。此回應所對應的函式呼叫的識別碼。由用戶端填入，以符合對應函式呼叫的 id。

    parts：FunctionResponsePart array 選填。構成函式回應的有序 Parts。各部分可能有不同的 IANA MIME 類型。
    data：Union type 函式回應部分的資料。

    inlineData：FunctionResponseBlob 行內媒體位元組。

    Tool¶

    模型可用於產生回應的工具詳情。

    Tool 是一段程式碼，讓系統能與外部系統互動，在模型的知識與範圍之外執行某個動作或一組動作。

    Properties：

    functionDeclarations：FunctionDeclaration array 選填。模型可用於函式呼叫的 FunctionDeclarations 清單。模型或系統不會執行函式。相反地，定義的函式可能會以 FunctionCall 的形式連同引數一起傳回給用戶端執行。模型可能決定呼叫這些函式的子集，方法是將 FunctionCall 填入回應中。下一個對話輪次可能包含 FunctionResponse，其 Content.role 為 'function'，作為下一個模型輪次的產生上下文。

    name：必填 string

    函式的名稱。必須為 a-z、A-Z、0-9，或包含底線、冒號、點與連字號，長度上限為 128。

    description：必填 string

    函式的簡要說明。

    parameters：Schema

    選填。說明此函式的參數。反映 Open API 3.03 Parameter Object 字串 Key：參數的名稱。參數名稱區分大小寫。Schema Value：定義參數所用類型的 Schema。

    parametersJsonSchema：object

    選填。以 JSON Schema 格式說明函式的參數。架構必須描述一個物件，其屬性即為函式的參數。例如：{ "type": "object", "properties": { "name": { "type": "string" }, "age": { "type": "integer" } }, "additionalProperties": false, "required": ["name", "age"], "propertyOrdering": ["name", "age"] } 此欄位與 parameters 互斥。

    response：Schema

    選填。以 JSON Schema 格式說明此函式的輸出。反映 Open API 3.03 Response Object。Schema 定義函式回應值所用的類型。

    responseJsonSchema：object

    選填。以 JSON Schema 格式說明此函式的輸出。架構指定的值即為函式的回應值。此欄位與 response 互斥。

    behavior：string enum 選填。指定函式 Behavior。目前僅 BidiGenerateContent 方法支援。

    可能的值：

    • UNSPECIFIED：此值未使用。
    • BLOCKING：若設定，系統會等待收到函式回應後才繼續對話。
    • NON_BLOCKING：若設定，系統不會等待收到函式回應。相反地，它會在維持使用者與模型之間對話的同時，嘗試在函式回應可用時加以處理。

    dynamicRetrievalConfig：DynamicRetrievalConfig 指定指定來源的動態擷取設定。
    mode：string enum 動態擷取中要使用的預測器模式。

    可能的值：

    • MODE_UNSPECIFIED：一律觸發擷取。
    • MODE_DYNAMIC：僅在系統判定有必要時才執行擷取。

    dynamicThreshold：number

    動態擷取中要使用的門檻。若未設定，會使用系統預設值。

    codeExecution：CodeExecution 選填。讓模型能在產生過程中執行程式碼。
    googleSearch：GoogleSearch 選填。GoogleSearch 工具類型。支援模型中 Google 搜尋的工具。由 Google 提供。
    timeRangeFilter：Interval 選填。將搜尋結果篩選至特定時間範圍。若客戶設定了開始時間，就必須設定結束時間（反之亦然）。

    startTime：string

    選填。區間的起始（含）。若有指定，符合此區間的 Timestamp 必須等於或晚於起始。

    endTime：string

    選填。區間的結束（不含）。若有指定，符合此區間的 Timestamp 必須早於結束。

    searchTypes：SearchTypes 選填。要啟用的搜尋類型集合。若未設定，預設啟用網路搜尋。
    webSearch：WebSearch 選填。啟用網路搜尋。僅傳回文字結果。
    imageSearch：ImageSearch 選填。啟用圖片搜尋。傳回圖片位元組。
    computerUse：ComputerUse 選填。支援模型直接與電腦互動的工具。若啟用，會自動填入電腦使用專屬的函式宣告。
    environment：必填 string enum 正在操作的環境。

    可能的值：

    • ENVIRONMENT_UNSPECIFIED：預設為瀏覽器。
    • ENVIRONMENT_BROWSER：在網路瀏覽器中操作。
    • ENVIRONMENT_MOBILE：在行動環境中操作。
    • ENVIRONMENT_DESKTOP：在桌面環境中操作。

    excludedPredefinedFunctions：string array

    選填。依預設，預先定義的函式會包含在最終的模型呼叫中。其中一些可以明確排除，不自動包含。這有兩個目的：1. 使用更受限／不同的動作空間。2. 改進預先定義函式的定義／指令。

    enablePromptInjectionDetection：boolean

    選填。是否在電腦使用請求上啟用提示詞注入偵測檢查。

    disabledSafetyPolicies：string enum array 選填。電腦使用的已停用安全政策。

    可能的值：

    • SAFETY_POLICY_UNSPECIFIED：未指定的安全政策。
    • FINANCIAL_TRANSACTIONS：金融交易的安全政策。
    • SENSITIVE_DATA_MODIFICATION：敏感資料修改的安全政策。
    • COMMUNICATION_TOOL：通訊工具的安全政策（例如 Gmail、Chat、Meet）。
    • ACCOUNT_CREATION：帳號建立的安全政策。
    • DATA_MODIFICATION：資料修改的安全政策。
    • USER_CONSENT_MANAGEMENT：使用者同意管理的安全政策。
    • LEGAL_TERMS_AND_AGREEMENTS：法律條款與協議的安全政策。
    urlContext：UrlContext 選填。支援 URL 上下文擷取的工具。
    fileSearch：FileSearch 選填。FileSearch 工具類型。從 Semantic Retrieval 語料庫擷取知識的工具。

    fileSearchStoreNames：必填 string array

    要從中擷取的 file_search_stores 名稱。範例：fileSearchStores/my-file-search-store-123

    topK：integer

    選填。要擷取的語意擷取區塊數量。

    metadataFilter：string

    選填。要套用於語意擷取文件與區塊的中繼資料篩選器。

    mcpServers：McpServer array 選填。要連接的 MCP 伺服器。
    transport：Union type 用於連接 MCPServer 的傳輸方式。

    Union 欄位 transport 只能是下列其中之一：

    streamableHttpTransport：StreamableHttpTransport 可串流 HTTP 請求與回應的傳輸方式。

    url：string

    MCPServer 端點的完整 URL。範例："https://api.example.com/mcp"

    headers：object

    選填：如有需要，驗證標頭、逾時等的欄位。

    timeout：string

    一般操作的 HTTP 逾時。

    sseReadTimeout：string

    SSE 讀取操作的逾時。

    terminateOnClose：boolean

    傳輸關閉時是否關閉用戶端工作階段。

    name：string

    MCPServer 的名稱。

    googleMaps：GoogleMaps 選填。讓模型的回應能以與使用者查詢相關的地理空間上下文接地的工具。

    enableWidget：boolean

    選填。是否在回應的 GroundingMetadata 中傳回小工具上下文權杖。開發人員可使用小工具上下文權杖，算繪帶有與模型在回應中參考之地點相關的地理空間上下文的 Google Maps 小工具。
