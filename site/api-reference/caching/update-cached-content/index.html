    更新快取內容¶

    PATCH https://generativelanguage.googleapis.com/v1beta/cachedContents/{id}

    更新 CachedContent 資源（僅到期時間可更新）。

    參數¶

    id: required string

    快取內容 ID。構成資源名稱 cachedContents/{id}。

    updateMask: string

    要更新的欄位清單。

    請求主體¶

    model: required string

    不可變。用於快取內容的 Model 名稱。格式：models/{model}

    expiration: Union type 指定此資源何時到期。

    聯合欄位 expiration 只能為下列其中之一：

    expireTime: string

    此資源被視為到期時的 UTC 時間戳記。無論輸入時傳送了什麼，輸出時一律會提供此值。

    ttl: string

    僅供輸入。此資源的新 TTL，僅供輸入。

    displayName: string

    選用。不可變。使用者為快取內容產生的具意義顯示名稱。最多 128 個 Unicode 字元。

    systemInstruction: Content 選用。僅供輸入。不可變。由開發人員設定的系統指令。目前僅支援文字。
    parts: Part array 構成單一訊息的已排序 Parts。各 Part 的 MIME 類型可能不同。
    data: Union type

    聯合欄位 data 只能為下列其中之一：

    text: string

    內嵌文字。

    inlineData: Blob 內嵌媒體位元組。

    mimeType: string

    來源資料的 IANA 標準 MIME 類型。支援類型範例：

    • 圖片：image/png, image/jpeg, image/jpg, image/webp, image/heic, image/heif, image/gif, image/avif
    • 音訊：audio/*, video/audio/s16le, video/audio/wav
    • 影片：video/*
    • 文字：text/plain, text/html, text/css, text/javascript, text/x-typescript, text/csv, text/markdown, text/x-python, text/xml, text/rtf, video/text/timestamp
    • 應用程式：application/x-javascript, application/x-typescript, application/x-python-code, application/json, application/x-ipynb+json, application/rtf, application/pdf 如需更多背景資訊，請參閱支援的檔案格式。

    data: string

    媒體格式的原始位元組。

    displayName: string

    選用。指定向模型提及此 blob 時所用的名稱（例如 "my_blob.png"）。當 verbalization_mode 設為 REFERENCE_ONLY 時，作為 blob 參照識別碼使用。

    functionCall: FunctionCall 模型傳回的預測 FunctionCall，其中包含代表 FunctionDeclaration.name 的字串，以及其引數與值。

    name: required string

    要呼叫的函式名稱。必須為 a-z、A-Z、0-9，或包含底線與連字號，長度上限為 128。

    id: string

    選用。函式呼叫的唯一識別碼。若有填入，用戶端會執行 function_call，並傳回帶有相符 id 的回應。

    args: object

    選用。以 JSON 物件格式表示的函式參數與值。

    functionResponse: FunctionResponse FunctionCall 的結果輸出，其中包含代表 FunctionDeclaration.name 的字串，以及包含函式任何輸出的結構化 JSON 物件，作為提供給模型的上下文。

    name: required string

    要呼叫的函式名稱。必須為 a-z、A-Z、0-9，或包含底線與連字號，長度上限為 128。

    response: required object

    以 JSON 物件格式表示的函式回應。呼叫端可使用任何符合函式語法的自選鍵來傳回函式輸出，例如 "output"、"result" 等。特別是當函式呼叫執行失敗時，回應中可加入 "error" 鍵，將錯誤詳細資訊傳回給模型。多媒體內容可透過包含單一 "$ref" 鍵的子物件納入，其值為 inline_data.display_name 或 file_data.display_name，是保存該多媒體的 FunctionResponsePart 的顯示名稱。請參閱多模態函式回應。

    id: string

    選用。此回應所對應函式呼叫的識別碼。由用戶端填入，以對應相對應的函式呼叫 id。

    parts: FunctionResponsePart array 選用。構成函式回應的已排序 Parts。各 Part 的 IANA MIME 類型可能不同。
    data: Union type 函式回應部分的資料。

    聯合欄位 data 只能為下列其中之一：

    inlineData: FunctionResponseBlob 內嵌媒體位元組。

    mimeType: string

    來源資料的 IANA 標準 MIME 類型。範例：

    • image/png
    • image/jpeg

    title: string

    description: string

    選用。參數的簡要說明。可包含使用範例。參數說明可使用 Markdown 格式。

    enum: string array

    maxItems: string

    minItems: string

    選用。Type.ARRAY 元素的數量下限。

    properties: object

    minProperties: string

    anyOf: Schema array

    選用。該值應對照清單中的任一（一個或多個）子結構描述進行驗證。

    default: object

    codeExecution: CodeExecution 選用。讓模型能在產生過程中執行程式碼。
