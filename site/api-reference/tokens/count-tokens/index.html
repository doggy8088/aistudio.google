    計算權杖數¶

    POST https://generativelanguage.googleapis.com/v1beta/models/{model}:countTokens

    對輸入的 Content 執行模型的 tokenizer，並傳回權杖數量。 請參閱權杖指南 進一步瞭解權杖。

    參數¶

    model: required string

    模型 ID，例如 gemini-2.5-flash。會組成資源名稱 models/{model}。

    要求主體¶

    contents: Content array 選用。作為提示詞提供給模型的輸入。設定 generate_content_request 時會忽略此欄位。
    parts: Part array 組成單一訊息的有序 Parts。各 Part 的 MIME 類型可能不同。
    data: Union type

    聯集欄位 data 只能是下列其中之一：

    text: string

    行內文字。

    inlineData: Blob 行內媒體位元組。

    mimeType: string

    來源資料的 IANA 標準 MIME 類型。支援的類型範例：

    • 圖片：image/png, image/jpeg, image/jpg, image/webp, image/heic, image/heif, image/gif, image/avif
    • 音訊：audio/*, video/audio/s16le, video/audio/wav
    • 影片：video/*
    • 文字：text/plain, text/html, text/css, text/javascript, text/x-typescript, text/csv, text/markdown, text/x-python, text/xml, text/rtf, video/text/timestamp
    • 應用程式：application/x-javascript, application/x-typescript, application/x-python-code, application/json, application/x-ipynb+json, application/rtf, application/pdf。更多上下文請參閱支援的檔案格式。

    data: string

    媒體格式的原始位元組。

    displayName: string

    選用。指定用來向模型參照此 blob 的名稱（例如 "my_blob.png"）。當 verbalization_mode 設為 REFERENCE_ONLY 時，作為 blob 的參照識別碼。

    functionCall: FunctionCall 模型傳回的預測 FunctionCall，其中包含代表 FunctionDeclaration.name 的字串，以及其引數與值。

    name: required string

    要呼叫的函式名稱。必須是 a-z、A-Z、0-9，或包含底線與連字號，長度上限為 128。

    id: string

    選用。函式呼叫的專屬識別碼。若有填入，用戶端應執行 function_call，並傳回帶有相符 id 的回應。

    args: object

    選用。JSON 物件格式的函式參數與值。

    functionResponse: FunctionResponse FunctionCall 的結果輸出，其中包含代表 FunctionDeclaration.name 的字串，以及包含函式任何輸出的結構化 JSON 物件，作為提供給模型的上下文。

    name: required string

    要呼叫的函式名稱。必須是 a-z、A-Z、0-9，或包含底線與連字號，長度上限為 128。

    response: required object

    JSON 物件格式的函式回應。呼叫端可使用任何符合函式語法的自選鍵來傳回函式輸出，例如 "output"、"result" 等。特別是當函式呼叫執行失敗時，回應可包含 "error" 鍵，將錯誤詳細資訊傳回給模型。多媒體內容可透過子物件納入，該子物件包含單一 "$ref" 鍵，其值為 inline_data.display_name 或 file_data.display_name，屬於持有該多媒體的 FunctionResponsePart。請參閱多模態函式回應。

    id: string

    選用。此回應所對應之函式呼叫的識別碼。由用戶端填入，以對應相應函式呼叫的 id。

    parts: FunctionResponsePart array 選用。組成函式回應的有序 Parts。各 Part 的 IANA MIME 類型可能不同。
    data: Union type 函式回應部分的資料。

    聯集欄位 data 只能是下列其中之一：

    inlineData: FunctionResponseBlob 行內媒體位元組。

    mimeType: string

    來源資料的 IANA 標準 MIME 類型。範例：

    • image/png
    • image/jpeg

    若提供不支援的 MIME 類型，將傳回錯誤。支援類型的完整清單請參閱支援的檔案格式。

    data: string

    媒體格式的原始位元組。

    displayName: string

    選用。blob 的顯示名稱。用來提供標籤或檔名以區分各個 blob，並可從 FunctionResponse.response 參照該 blob（例如透過 {"$ref": "DISPLAY_NAME"}）。

    fileData: FunctionResponseFileData 以 URI 為基礎的資料。

    fileUri: required string

    URI.

    mimeType: string

    來源資料的 IANA 標準 MIME 類型。若提供不支援的 MIME 類型，將傳回錯誤。支援類型的完整清單請參閱多模態函式回應與支援的檔案格式。

    displayName: string

    選用。檔案的顯示名稱。用來提供標籤或檔名以區分檔案資料，並可從 FunctionResponse.response 參照該檔案（例如透過 {"$ref": "DISPLAY_NAME"}）。

    metadata: Union type 控制資料的額外預處理。當 inline_data 或 file_data 存在時設定此欄位，以設定每個部分的靜態媒體預處理。

    聯集欄位 metadata 只能是下列其中之一：

    videoMetadata: VideoMetadata 選用。影片中繼資料。僅應在影片資料以 inline_data 或 file_data 呈現時指定此中繼資料。

    startOffset: string

    選用。影片的開始偏移。

    endOffset: string

    選用。影片的結束偏移。

    fps: number

    選用。傳送給模型的影片幀率。若未指定，預設值為 1.0。fps 範圍為 (0.0, 24.0]。

    contentLayers: string enum array 選用。要傳回的內容層。若為空，預設為 [FRAMES, AUDIO]。

    可能的值：

    • CONTENT_LAYER_UNSPECIFIED: 預設值。
    • FRAMES: 擷取影片影格。
    • AUDIO: 擷取音軌。
    • TRANSCRIPT: 擷取音訊逐字稿。
    documentMetadata: DocumentMetadata 選用。文件中繼資料。僅應在文件資料以 inline_data 或 file_data 呈現時指定此中繼資料。

    startPage: integer

    選用。起始頁，以 1 起算，包含起始頁。

    endPage: integer

    選用。結束頁，以 1 起算，包含結束頁。

    contentLayers: string enum array 選用。要傳回的內容層。若為空，當設定了 DocumentMetadata 時預設為 [PAGE_IMAGE]；若未設定 DocumentMetadata，則使用預設的文件處理方式（例如 PDF 的頁面影像）。

    可能的值：

    • CONTENT_LAYER_UNSPECIFIED: 預設值。
    • PAGE_IMAGE: 轉譯後的頁面影像。
    • PAGE_TEXT: 擷取的頁面文字。
    spreadsheetMetadata: SpreadsheetMetadata 選用。試算表中繼資料。僅應在試算表資料以 inline_data 或 file_data 呈現時指定此中繼資料。

    visibleCells: string

    選用。要擷取的儲存格範圍，以 A1 標記法表示（例如 "A1:D10"）。若未設定，將使用工作表已佔用的完整範圍。

    sheetIndex: integer

    選用。要擷取的工作表索引，以 1 起算，依活頁簿順序。若未設定，會擷取全部工作表。

    contentLayers: string enum array 選用。要傳回的內容層。若為空，當設定了 SpreadsheetMetadata 時預設為 [DATA, FORMULAS]。

    可能的值：

    • CONTENT_LAYER_UNSPECIFIED: 預設值。
    • DATA: 儲存格值、合併儲存格與格式。
    • FORMULAS: 公式運算式及其計算結果。
    • VISUAL: 工作表的轉譯影像。
    audioMetadata: AudioMetadata 選用。音訊中繼資料。僅應在音訊資料以 inline_data 或 file_data 呈現時指定此中繼資料。

    startOffset: string

    選用。音訊的開始偏移，相對於音訊串流的開頭。

    endOffset: string

    選用。音訊的結束偏移，相對於音訊串流的開頭。

    mediaProcessing: string enum 選用。模型如何處理此部分的媒體以便理解。僅對影片部分（inline_data 或 MIME 為影片的 file_data）有意義。非影片部分會忽略此欄位。

    可能的值：

    • MEDIA_PROCESSING_UNSPECIFIED: 預設為模型專屬的處理方式。
    • STATIC: 固定速率的幀擷取。所有幀都放入上下文。
    • AGENTIC: 模型驅動的動態導覽。建議用於大多數使用情境。
    mediaResolution: V1mainMediaResolution 選用。輸入媒體的媒體解析度。
    value: Union type 媒體解析度等級。

    聯集欄位 value 只能是下列其中之一：

    level: string enum 指定媒體所使用的權杖化品質。供 Gemini API 支援使用。

    可能的值：

    • MEDIA_RESOLUTION_UNSPECIFIED: 尚未設定媒體解析度。
    • MEDIA_RESOLUTION_LOW: 媒體解析度設為低。
    • MEDIA_RESOLUTION_MEDIUM: 媒體解析度設為中。
    • MEDIA_RESOLUTION_HIGH: 媒體解析度設為高。
    • MEDIA_RESOLUTION_ULTRA_HIGH: 媒體解析度設為超高。

    willContinue: boolean

    選用。表示函式呼叫將繼續，且會傳回更多回應，使函式呼叫成為產生器。僅適用於 NON_BLOCKING 函式呼叫，其他情況會忽略。若設為 false，後續回應將不予考慮。允許傳回空的 response 並搭配 will_continue=False，表示函式呼叫已完成。這仍可能觸發模型生成。若要避免觸發生成並結束函式呼叫，請另外將 scheduling 設為 SILENT。

    選用。套用至下一個權杖 logprobs 的頻率懲罰，乘以每個權杖到目前為止在回應中出現的次數。正值的懲罰會依權杖已使用的次數比例，降低再次使用已用過權杖的意願：權杖用得越多，模型就越難再次使用該權杖，從而增加回應的詞彙量。注意：負值的懲罰會依權杖已使用的次數比例，鼓勵模型重複使用權杖。較小的負值會減少回應的詞彙量；較大的負值會使模型不斷重複某個常見權杖，直到達到 max_output_tokens 上限。
