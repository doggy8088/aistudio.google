    建立互動¶

    您目前檢視的是 Interactions API 的 beta 版本。端點位於 /v1beta/ 之下。另有穩定的 v1 版本 可供使用。

    POST https://generativelanguage.googleapis.com/v1beta/interactions

    建立新的互動。

    請求主體¶

    model：ModelOption 用於產生互動的 Model 名稱。未提供 agent 時為必填。

    • gemma-4-26b-a4b-it：Gemma 4 26B A4B IT
